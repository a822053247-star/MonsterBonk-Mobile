# 绯花漂游术士五方向素材

- `source.png`：用户提供的2172×724原图，保留原样。
- `runtime.normalized.png`：1280×256，五个256×256格，依次为正面、右前、右侧、右后、背面；左向由运行时镜像。
- `crop.json`：各方向在原图中的边界、统一缩放比例和放置位置。
- 重建：项目根目录执行 `python scripts/recrop-crystal-crawler.py --species scarlet-flower`；额外传入图片路径可以更新原图。

复用晶甲重炮的确定性裁剪流程，按原图真实透明间隔分割，不等分原图。去除alpha低于24的背景杂点，其余保留原色与细节；各帧统一缩放，最大宽224/高200，底部对齐(128,240)。避免右前和右侧帧混入相邻方向的花瓣、环形水晶。基础正面单图同步更新，预览为 `artifacts/scarlet-flower-recrop.png`。不修改显示尺寸配置、碰撞或战斗属性。
