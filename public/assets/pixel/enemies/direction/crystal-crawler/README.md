# 晶甲重炮五方向素材

- `source.png`：用户提供的2172×724原图，保留原样。
- `runtime.normalized.png`：1280×256，五个256×256格，顺序为正面、右前、右侧、右后、背面；左侧由运行时镜像。
- `crop.json`：原图轮廓边界、统一缩放比例及各帧放置位置。
- 重建：在项目根目录运行 `python scripts/recrop-crystal-crawler.py`；传入图片路径可替换原图。

按实际透明间隔切分，不等分原图。清除alpha低于24的背景杂点，保留主体原色及细节；五个方向使用同一比例，最大宽224、高200，落点对齐至(128,240)。侧面较宽，因此宽度限制优先，实际主体高度约166–171像素，保持原图比例，不拉伸或截断炮口。基础单图同步取正面格。预览输出至 `artifacts/crystal-crawler-recrop.png`。
