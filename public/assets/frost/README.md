# 霜晶弹与水冰冻结

素材来自用户提供的「霜晶弹冰冻效果素材包_俯视角重绘」目录，PNG原样复制。

- crystal.png：源文件「霜晶弹_128x128.png」实际为1254×1254冰晶簇。
  弹体与碎屑用UV选取其中一枚尖晶（337,280,132,260），保留原图，不整簇充当子弹。
- freeze-shell.png：「冻结效果_俯视角_透明中心_128x128.png」，用于敌人脚下的透明中心冰壳。
- 两种素材均在世界XZ平面渲染；保留尖晶比例，由现有镜头提供俯视透视。
- 冻结冰壳持续稳定显示，解冻时淡出并散落碎晶，不循环跳帧或高频闪烁。

此批只接入霜晶弹和水冰冻结。包内冰川滑痕及碎冰震环留作后续独立技能素材。
