# 霜晶弹与水冰冻结

素材来自用户提供的「霜晶弹冰冻效果素材包_俯视角重绘」目录，PNG原样复制。

- crystal.png：源文件「霜晶弹_128x128.png」实际为1254×1254冰晶簇。
  弹体与碎屑用UV选取其中一枚尖晶（337,280,132,260），保留原图，不整簇充当子弹。
- freeze-shell.png：「冻结效果_俯视角_透明中心_128x128.png」，用于敌人脚下的透明中心冰壳。
- 两种素材均在世界XZ平面渲染；保留尖晶比例，由现有镜头提供俯视透视。
- 冻结冰壳持续稳定显示，解冻时淡出并散落碎晶，不循环跳帧或高频闪烁。

- shatter-ring.png：原包「碎冰震环_6帧_3x2.png」，1536×1024。按3×2顺序播放一次；着色器压低原图蓝色底雾并挖空中心，避免矩形底与遮挡角色。
- glacier-trail.png：「冰川滑痕_俯视角_三种变体图集_768x256.png」，三种静态变体按铺放次序轮换并沿移动方向旋转。仅淡入淡出，不循环换帧。原图冰面透明度较低，着色器提高显示透明度，不改动PNG。

碎冰震环、冰川滑痕现为独立技能卡，最高5级，不占武器槽；与霜晶弹共用霜寒/水冰冻结规则。逻辑池分别2环、24段，死亡、换波清场与重开均清理。
