技能图标分别使用「翠绿荆棘弦月战环.png」「冰霜水月斩.png」原图。

所有战斗素材在世界XZ平面旋转，由现有2.5D镜头产生透视；不朝镜头竖立、不额外压扁。
第一版没有使用旋转精灵表：单张环刃的程序自转能保持轮廓连续。
