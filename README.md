## 最简单的打开方式

1. 双击本目录的 **启动游戏.cmd**。
2. 等待命令窗口显示 `Local: http://localhost:5173/`，浏览器会自动打开。
3. 点击「开始冒险」。运行时请保持命令窗口打开，关闭窗口就会停止服务器。
4. 如果服务器已经启动，直接打开 <http://localhost:5173/> 即可。

电脑使用 **WASD / 方向键**移动，**空格 / Shift** 冲刺，**J** 跳跃，也可以用鼠标拖动左下角摇杆。右上角可暂停，Esc 可以暂停或继续。

## 在手机上打开

1. 保持电脑上的游戏服务器运行。
2. 手机和电脑连接同一个 Wi-Fi。
3. 在手机浏览器中输入 Vite 窗口里 **WLAN 对应的 Network 地址**。
   本次启动检测到的地址是 **http://172.31.197.230:5173/**，电脑换网络后地址可能变化。
4. 关闭手机的方向锁定，横过来，点击「开始冒险」。
5. 左手拖动摇杆，右手点冲刺，可以同时操作；移动端已移除跳跃按钮。电脑 J 仍保留原有纯表现跳跃，不影响地面战斗或碰撞。升级时停止战斗，松开手指后轻点一张卡牌；选卡后重新按住摇杆移动。

如果手机打不开：确认地址不是 `localhost`，确认在同一 Wi-Fi，检查 Windows 是否允许 Node.js 在当前局域网中访问。访客 Wi-Fi 的设备隔离也可能阻止连接。未自动修改防火墙。

iPhone Safari 不依赖强制横屏或全屏；不支持全屏时会隐藏全屏按钮。竖屏会显示旋转提示，游戏中转成竖屏或切后台会暂停。恢复横屏后点击「继续冒险」。

## 第二阶段：怪物与战斗

| 敌人 | 外观 | 生命 | 速度 | 接触伤害 | 掉落经验 |
| --- | --- | ---: | ---: | ---: | ---: |
| 普通怪「赤团」 | 橙红色圆团、小角 | 30 | 1.25 | 8 | 3 |
| 快速怪「疾芽」 | 黄色瘦高、长角 | 18 | 2.7 | 6 | 2 |
| 坦克怪「岩甲」 | 蓝色大体型、深色甲壳 | 100 | 0.75 | 16 | 8 |

速度单位为场景单位/秒，玩家基础移动速度为 4.6。地图、玩家模型、原摄像机与摇杆均保留。

- 开局约 2.6 秒后开始生成敌人，前三只依次介绍三种类型，之后随机混合。敌人从玩家周围 8–12 个场景单位处生成，避开地图外和障碍，出现前有 0.75 秒橙色预警圈。敌人追逐玩家并绕开树干、岩石和其他敌人；远离玩家 29 个单位后回收。
- 玩家无需瞄准或点击攻击。自动选择射程 10.5 内、已出生、仍存活、未被树干或岩石挡住的最近敌人。每 0.44 秒发射一颗可见的紫白魔法弹，单次伤害 18。魔法弹是实际飞行碰撞，不是直接扣血；使用线段检测防止穿过小怪。
- 敌人受击会闪白、击退、显示受损血条与魔法碎光。玩家碰到敌人会掉血、闪烁并出现屏幕边缘红光；受到伤害后 0.85 秒内不再受到接触伤害，多个重叠敌人每次取最高伤害。
- 敌人死亡掉落绿色经验晶球，靠近 3 个场景单位后自动吸附。经验只在真正收集后计入 HUD，达到阈值时升级并获得一次强化选择。
- HUD 实时显示血量、击败数与经验。血量归零后显示本局结果，可以「再来一次」。暂停菜单也可直接「重新开始」。重开和返回主菜单都会清空所有敌人、魔法弹、掉落、受击效果、计数和冷却。
- 战斗与移动共用 60 Hz 固定时间步。生成、追逐、发射、伤害无敌时间、魔法弹寿命和吸附均使用秒数推进，暂停/后台/竖屏期间不计算战斗。
- 固定池上限为 **48 个敌人、24 颗魔法弹、96 个经验球、48 组短时特效**，重复使用这些对象。经验球满池时将经验合并到最近的已有球，避免丢失经验。战斗显示采用实例化批次，共享几何体和材质，不为每次生成/击杀新建 GPU 资源。

## 第三阶段：升级与技能强化

首次升级需要 **8 点经验**，之后每一级的需求增加 4 点（8、12、16、20……）。HUD 同时显示累计经验、当前等级和本级经验进度。

升级时立即冻结移动、敌人、魔法弹、伤害、技能周期与计时。中央通常显示三张不同的有效卡牌，轻点一张就会应用强化并继续。如果一次收集的经验跨越多级，会保留溢出经验并逐次选卡，全部选完才恢复战斗。

| 技能 | 每级效果 | 上限 |
| --- | --- | ---: |
| 魔力浓缩 | 魔法弹基础伤害 +20% | 5 |
| 施法节拍 | 基础攻击频率 +15% | 5 |
| 分枝魔法 | 每次施法投射物 +1，保留中心弹并增加侧向弹 | 3 |
| 蓬勃生长 | 最大生命 +20，同时恢复 20 点生命 | 5 |
| 草叶轻步 | 基础移动速度 +10%，冲刺速度保持原值 | 5 |
| 远星回响 | 基础锁敌范围 +15%，同步延长弹体寿命 | 5 |
| 伴星魔法球 | 1/2/3 颗环绕球，伤害 12/18/24，轨道半径 2.2/2.4/2.6 | 3 |
| 草原冲击波 | 周期 4.5/4/3.5 秒，伤害 24/34/44，范围 3.8/4.6/5.4 | 3 |

- **叠加规则**：同类百分比强化按基础值相加，不连续乘算。例如伤害两级为 18×1.4=25.2；攻速两级为原频率的 1.3 倍，间隔为 0.44÷1.3 秒。不同种类的技能同时生效。魔法弹伤害强化不额外改变两个新技能的独立伤害。
- **卡池与满级**：卡牌不重复，不出现已满级或未提供的选项。全部技能合计 34 次强化，角色最高 35 级；全满后显示 MAX，不再弹出升级窗口，仍可继续收集并统计经验。最后只剩一或两种未满级技能时，仅显示这几种有效卡，不用空卡或无效卡补足三张。
- **防误触**：打开升级时清空键盘/摇杆/冲刺输入并释放指针捕获，HUD 暂时不可操作。必须在当前卡牌上重新按下并松开才算选择；旧摇杆手指松开、上一组卡牌的延迟点击都不选卡。新卡有 180ms 的 UI 防连点保护，不推进游戏时间。电脑也可聚焦卡牌后按 Enter 选择。
- **新技能计算**：环绕球使用固定步长旋转和碰撞，每个敌人有 0.55 秒环绕伤害间隔；冲击波逐渐扩散，同一波对同一只敌人只伤害一次。预警出生中的敌人不会受这些技能伤害。波纹最多同时存在 2 组，环绕球最多 3 颗，均采用共享资源的实例化显示。
- **重开**：等级、经验、技能等级、加成、环绕角度、冲击波、未选奖励和卡牌状态都会重置；只有本局生效，没有跨局存档。
- **配置位置**：`src/progression.ts` 集中定义技能说明、颜色、等级上限、每级效果和经验曲线；`Combat` 与 HUD 使用同一份计算结果。

还没有接入装备系统、音效、存档、Capacitor 或 Android/iOS 安装包。

## 开发命令

需要 Node.js 22.12+（已在本机 Node.js 24.14.1 安装依赖）。在项目目录打开终端：

```powershell
npm install
npm run dev
npm run build
npm run preview
```

`npm run build` 会先做严格 TypeScript 检查，然后输出静态资源到 `dist/`。不要双击 `dist/index.html`；通过本地服务器或静态网站托管打开。构建采用相对路径，后续可将 `dist` 配置为 Capacitor 的 `webDir`，原生壳与平台工程将在后续阶段接入。

浏览器测试：

```powershell
npx playwright install chromium webkit
npm test
```

测试包括独立战斗模拟和真实浏览器操作：三种追逐差异、选敌过滤、魔法弹命中/死亡/经验、接触伤害与无敌时间、贯穿检测、边界出生、30/60/120 Hz 固定步结果一致、3 分钟模拟和满池经验合并、重置清理；以及摇杆、双指移动时自动战斗、HUD、经验吸收、暂停、重开、旋转与后台处理。双指手势通过 Chromium CDP 注入；Windows WebKit 不代表已在 iPhone 真机验收，后台事件测试使用可控输入。

## 请在真实手机上测试

建议分别使用 Android Chrome 和 iPhone Safari，先进行 3–5 分钟的一局：

1. **边走边战斗**：一直按住摇杆移动，观察魔法弹自动飞向敌人、击中后出现闪白和血条；再用另一根手指点冲刺，确认移动和射击都不中断，松手后角色停下。
2. **三种敌人**：确认普通橙红怪、黄色快速怪、蓝色坦克都能出现并追逐；黄色明显更快，蓝色需要更多次命中。预警圈期间应不造成伤害。
3. **血量与失败**：主动靠近敌人，确认掉血、屏幕边缘变红，短暂无敌期间不会瞬间连续扣光血；生命到 0 后出现结果，怪物与计时停止。
4. **经验与计数**：击败敌人后先远离绿色经验球，确认经验未增加；靠近后球飞向玩家并消失，经验只增加一次，击败数与实际击败一致。
5. **重开清理**：分别从暂停和失败画面重新开始，重复 5 次；血量恢复 100、击败/经验归零，地图上不残留旧怪物、弹体、经验球或预警圈。
6. **切后台与旋转**：战斗中切到其他 App 10 秒，再返回；应处于暂停状态，点击继续后才恢复，没有后台扣血或突然补发。转竖屏再横屏也应暂停，安全区域内的血量、摇杆与冲刺按钮不被刘海/底部手势条遮住。
7. **手机性能**：持续玩 5 分钟，观察敌人变多时是否明显卡顿或发热，以及连续冲刺/吸收多颗球时的表现。自动化测试无法确认实际手机帧率、功耗和低内存恢复，尚需真机体验。
8. **真实升级与选卡**：收集够 8 点经验后应出现卡牌，怪物和计时停止；保持原摇杆手指滑到卡牌再松开应不选卡。用新的一次轻点选卡后恢复，摇杆需要重新按住，不能自己继续跑。
9. **强化效果**：观察额外魔法弹、血量上限、移动与施法速度、远距离选敌；习得环绕球与冲击波后，确认可见且能击中怪物。重复强化同一技能，检查卡牌显示的下一级数值与上限。
10. **升级时切后台/旋转**：卡牌打开期间切换 App 或旋转手机，返回后仍应等待选择；选卡与画面恢复不能出现后台伤害或丢失奖励。

## 第四阶段：表现、声音与画质

主菜单、暂停菜单或游戏右上角都可以打开「画质与声音设置」。战斗中打开会立即暂停，关闭后回到暂停菜单，需要点击「继续冒险」。设置保存在当前浏览器本地，不需要账号。

- **自动**：以 60 帧为目标，持续负载较高时逐步降低像素比，必要时改为 30 帧目标；恢复采用更长观察窗口，避免来回切换。
- **省电**：30 帧渲染目标，降低草花装饰密度、粒子和拖尾数量，绘图缓冲区不超过约 130 万像素。
- **清晰**：60 帧目标，最高像素比 1.75；负载较高时依然降低清晰度。自动/清晰绘图缓冲区不超过约 240 万像素。
- 暂停、后台与旋转不会计入画质采样；恢复时重新开始采样。以上是运行策略和预算，不能据此认定任何手机已达到 30 / 60 FPS。

芽噜增加小角、獠牙、背鳞、爪趾与尾巴，具有呼吸、眨眼、摆尾、走路、冲刺倾身、跳跃与受击变形/闪色。魔法拖尾使用固定容量的实例槽位；死亡怪兽拆散成缩小的彩色碎块。敌人继续使用 InstancedMesh；投射物和粒子池复用，不因击杀不断创建 GPU 对象。角色静态细节按材质合并，云朵也改成实例批次，没有实时阴影或昂贵后处理。

镜头对树干、树冠和岩石执行带间隙的体积检测，受阻时收近，离开遮挡后平滑恢复。跳跃只影响角色的显示高度，XZ 碰撞、受击判定、自动攻击和升级计算保持原来的规则。

背景音乐是一段本项目原创、程序合成的循环小调，音效也由 Web Audio 生成。首次点击开始后才初始化音频；音乐和音效可以分别关闭。暂停、设置、升级、失败和后台停止声音，最多同时播放 8 个短音效。没有下载音频素材。浏览器不提供音频时游戏仍可运行。浏览器自动化只能验证音频状态与开关，实际听感和 iPhone 静音模式需要真机确认。
