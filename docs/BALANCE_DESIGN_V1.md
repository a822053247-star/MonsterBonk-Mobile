# MonsterBonk 专项平衡方案 V1

状态：**设计提案，尚未实施、尚未验证达标**。日期：2026-10-23。

依据：[当前内容和数值基线](../item.md)、当前工作区的战斗/成长/波次源码，以及[此前 Boss 对比样本](../artifacts/boss-difficulty-balance.json)。本文只定义下一阶段要验证的数值与规则，不修改代码，不覆盖 `item.md` 中的现状。

## 1. 要做成怎样的游戏

保留单幻兽、移动躲避、自动攻击、三武器、升级、融合、六波及 Boss。武器、技能、遗物在闯关和无尽使用同一套玩家数值，区别放在导演节奏、跨轮成长和胜负条件。

本作的乐趣应来自：先靠起始武器清怪，遇到第一次压力，拿到互补攻击后反击，形成连锁后享受清场，再用已经成型的构筑迎接可读的 Boss。三种起始幻兽都必须能完成这一过程；水系不能因选择控制而天然输给最终计时。

目标整局情绪线：

**轻松入门 → 第一次吃紧 → 中等压力 → 明显变强、轻松收割 → 精英考验 → 喘息 → 混编考验 → 集中成长与商店 → 中等偏难 Boss。**

视觉成长也属于平衡目标：选定部分攻击，让武器升级和融合同时带来更大的攻击主体、实际命中足迹及命中反馈。玩家不仅看到伤害数字增加，还应看到火浪展开、潮刃变宽、融合爆炸覆盖更多敌人。具体规格见3.4节；不把所有攻击都缩小到同一份覆盖预算。

“轻松”不等于空场。收割段应有足够的草团/晶屑供玩家击杀和拾取，但减少高速冲刺、爆炸预警和堵路重甲。难度由危险组合和可用空间决定，不由屏幕上敌人总数单独决定。

### 1.1 保留的边界

- 闯关波长仍为 **65/70/75/75/80/90 秒**，前五波合计365秒；Boss必须击败，闯关90秒仍未击败则失败。
- 第1–5波保持现有连续战斗边界，第5波后商店；不增加每波回血、额外商店、局外养成、装备品质、武器槽或新敌人。
- 无尽每六波循环、第五波商店、第六波 Boss；90秒后保留加时狂暴，不把闯关超时失败套到无尽。
- 不根据玩家当前伤害临时给敌人补血，也不根据连败偷偷改数值。收割窗口写进导演时间表，玩家能够学习。
- 敌人/普通弹体等池容量保留；先调组成、触发频率和范围，不靠扩大池子维持强度。

### 1.2 目标，不是本次实测结论

| 检查项 | 首轮目标 |
|---|---|
| 首次升级 | 正常追击和拾取时约15–22秒；过慢先检查出生距离和经验可达性 |
| 第一种武器＋技能自动融合 | 45–90秒有合理获得机会，不要求抽到特定稀有物 |
| 三波后 | 至少一把3级主武器，或两把有互补作用的武器；有一次明确的清场提升 |
| 五波后、商店前 | 常规拾取策略约19–23级；重点构筑可完成一种融合或一条技能进化 |
| Boss入场 | 大约21–27次已应用奖励（升级选择＋商店购买，不等同角色等级） |
| 成熟普通构筑击败Boss | 35–65秒；防御偏重但合理构筑允许65–85秒 |
| 成熟强协同构筑 | Boss约25–40秒；不能稳定在12秒内跳过几乎全部技能 |
| 熟悉移动的新玩家 | 前两波大多能体验；最终失败应能解释为躲避/拾取/构筑问题 |
| 三幻兽差异 | 同种子、相似投入的成型时间中位数差不超过15%；不要求打法相同 |

不把脚本通过比例当作人类胜率。此前9个固定样本中6个进入Boss波，加强后3个在观察期内通关，且水系在前五波和Boss均有失败；这能提示弱项，不能证明所有玩家已经处于中等难度。

## 2. 先解决的结构问题

| 当前问题 | 本方案处理 | 对体验的作用 |
|---|---|---|
| 普通投射副武器×1.6/1.9间隔，近战/刃/雷无该惩罚 | 投射副武器改为×1.35/1.55；独立攻击仍独立调度 | 降低“拿到新武器却没变强”的落差 |
| 多重弹数量、击杀连爆、攻速多次相乘 | 多重额外弹按75%伤害；削减少数放大链条的极端系数 | 减少天胡与普通局差距，保留弹数与连锁爽感 |
| 范围半径乘算导致实际面积爆增 | 按攻击族设置最终半径上限；适当降低过载代价和收益 | 减少跨屏清场，同时不把范围遗物做成负收益陷阱 |
| 水泡/控制流打群怪安全，但Boss收益偏低 | 小幅加强水泡直击；部分需要持续覆盖/往返的技能提高Boss系数 | 不强制水系玩家转火系才有通关资格 |
| 部分独立技能不吃全局魔力，部分吃 | 伴星/冲击波纳入全局魔力，同时补充精英/Boss系数 | 面板解释一致，避免后期技能无成长或意外无减伤 |
| 无限叠技能、跨轮敌方倍率最终全部封顶 | 不新增技能槽；无尽后段继续增加生命压力，危险数量、伤害和速度有上限 | 完整构筑后仍有挑战，又不靠满屏高速怪制造必死 |
| 收割段仍可能承接上一段的大量危险敌 | 新危险供给提前停止、精英下一招间隔延长；不删除已经出现的怪 | 让时间表中的“喘息”能在场上兑现 |

下文未列为改动的字段，明确沿用 `item.md`；不暗含重做伤害类型、攻击形状或新增元素反应。

## 3. 成长、投射调度与控制的共用规则

### 3.1 全局成长

| 项目 | 现状 → 提案 | 理由 |
|---|---|---|
| 魔力浓缩 | 每级＋20%，最多5级，保持 | 保留容易理解的长期伤害投入 |
| 施法节拍 | 每级＋15%频率，最多5级，保持 | 不在基础攻速和所有武器上同时降强度 |
| 分枝魔法 | 最多4枚，保持；第1枚100%，额外每枚75% | 总直击系数由1/2/3/4变为1/1.75/2.5/3.25 |
| 生命 | 每级基础上限＋20、最多5级，保持 | 防御选择必须能容错一次普通攻击 |
| 移速 | 每级＋10%、最多5级，保持 | 不破坏已经可躲避的地震路线和冲刺预警 |
| 射程 | 每级＋15% → ＋12%，最多5级 | 满级×1.60，减少单纯站远自动清场 |
| 副武器投射间隔 | 1/1.6/1.9 → 1/1.35/1.55 | 保留主武器价值，减少新武器惩罚 |
| 连发节奏 | 同轮0.08秒、轮间0.18秒，保持 | 避免用不可见的更高发射密度补强 |
| 临时攻速叠加 | 乘算后频率额外倍率上限1.50 | 只限沙漏/血契/疾风等临时层，不限制永久攻速成长 |

额外主弹的75%应在该枚弹的实际伤害快照中生效，后续分裂/蒸爆等读取该快照；不能让削弱的额外弹仍按100%原伤产生派生。主施放计数仍按整轮一次，多重弹不多次触发骨骰。

临时攻速上限必须在详情中可见；不把独立技能的周期自动纳入武器攻速，不新增隐藏的“全技能冷却缩减”。

### 3.2 范围上限

| 攻击族 | 最终半径/射程上限 | 范围升级如何生效 |
|---|---:|---|
| 普通主投射物 | 射程16 | 基础射程×全局射程×适用遗物 |
| 火焰横扫 | 半径6.0，保留当前上限 | 等级半径×全局射程×适用面积倍率，最后截断 |
| 环刃荆轮 | 常规轨道4.2，5级额外扩圈最多0.6 | 轨道吃全局射程；刃面面积倍率最多1.4 |
| 回旋潮刃 | 射程13 | 射程与刃面分开；刃面面积倍率最多1.4 |
| 雷芽 | 首次锁定13，后续跳距6.5 | 全局射程增加锁定/跳距，但不增加目标数 |
| 火种/殉爆爆炸 | 半径3.6 | 等级、路线、油壶等相乘后最后截断 |
| 沸腾核心蒸爆 | 半径3.5 | 不把普通火花射程倍率当面积倍率 |
| 双武器融合溅射 | 半径2.8 | 支持卡、遗物乘算后截断；分裂子弹另结算 |
| 普通独立技能 | 使用第5节自身等级表 | 不默认吃武器射程或过载核心 |
| 组合技能进化 | 使用第7节固定足迹 | 本身足够大，不再被过载扩到整个屏幕 |

半径上限只限制伤害/控制覆盖，不以丢弃视觉实例的方式偷减伤害。达到上限的升级需显示实际前后值，不能继续写“＋30%半径”却完全无收益。

### 3.3 减速和冻结

普通减速统一取当前有效效果中最慢的一项，**不再把水泡减速与霜寒再相乘**。最终剩余移动速度下限：普通敌人30%、精英55%、Boss85%。冻结是独立状态，不套此移动下限。

保留普通冻结1.25秒、精英0.45秒、解冻后2.5秒抗性，Boss免疫冻结。Boss仍可被轻微减速，但锁定冲锋的方向和预警不能靠冻结取消。

水/冰消耗湿润及遗物毒印等事件顺序保持明确；同一份湿润不能既完整触发蒸爆又完整触发冻结。没有新增“水电感电”“火草克制”等内容。

### 3.4 视觉冲击与真实范围同步成长

这是本方案的明确设计方向：**部分攻击变大，真实范围相应变大，升级和融合要有一眼能看出的形态进步。** 以下规格替代本方案早稿中相应较小的范围；其余伤害/频率沿用目标表，不把扩大覆盖自动解释为增加每个敌人的伤害。

#### 优先放大的攻击

| 攻击 | 目标实际范围 | 视觉表现 | 较当前游戏的变化 |
|---|---|---|---|
| 火焰横扫 | L1–L5半径2.8/3.3/3.8/4.4/5.0；角度180/220/260/300/360°；最终半径上限6 | 主火浪与扇形命中边界同步展开；5级形成完整大火环，外沿余烬随后消散 | 当前5级基础半径4.4→5.0，同角度覆盖面积约＋29% |
| 回旋潮刃 | 刃碰撞半径0.70/0.80/0.90/1.00/1.10；射程仍8–10.6 | 刃面逐级加宽，去程水刃和回程尾迹明显区分，保持能看见敌人 | 当前5级刃半径0.93→1.10；按真实扫掠宽度增强，非凭空加大往返伤害次数 |
| 蒸汽彗星 | 融合3/4/5级溅射半径1.6/1.8/2.0；修饰后最终上限2.8 | 一个清晰的蒸汽冲击主体，爆心亮起、外环扩散，升级后爆炸更饱满 | 当前融合基础半径1.35固定；提案增加等级覆盖成长 |
| 藤潮囚泡 | 融合3/4/5级溅射半径1.65/1.85/2.05；修饰后最终上限2.8 | 水泡撑开后藤纹沿命中边缘浮现，透明内部保留敌人轮廓 | 当前基础半径1.5固定；控制覆盖与视觉同步成长 |
| 苍蓝震爆 | L1–L5半径3.5/3.925/4.35/4.775/5.2 | 从短暂聚光到大水环展开，中心冲击短而强；伤害时刻仍是0.16秒的一次震爆 | 当前5级半径4.9→5.2，覆盖面积约＋13% |
| 梦印绽放 | 绯梦弹叠满三层触发的绽放半径2.6；适用面积倍率最多1.6，最终半径上限3.6 | 三层印记集中后绽放一朵更大的粉色冲击花，区别于普通弹命中 | 当前基础绽放半径2.2→2.6，覆盖面积约＋40% |

这里的面积比例按同角度圆/扇形半径平方估算；不等于同比实际伤害提升。潮刃是沿路径扫掠的形状，不能拿静态圆面积估算其收益。

#### 主投射物的主体与碰撞大小

火花、水泡、飞叶、霜晶、绯梦、花种保留各自的射程、穿透、印记和命中次数规则。增加实体宽度不等于给它们全部添加爆炸；不穿透的弹仍在首个命中目标处结算。

| 主投射物 | L1→L5实际碰撞半径 | 视觉成长方向 |
|---|---:|---|
| 火花弹 | 0.20→0.26 | 火核略变大，尾焰变长，主要爆发交给火种爆炸 |
| 水泡弹 | 0.24→0.34 | 更饱满、轮廓清楚的透明泡体，形成与火花不同的体量感 |
| 飞叶弹 | 0.20→0.26 | 增加叶刃主体宽度，保留狭长轮廓和穿透辨识度 |
| 霜晶弹 | 0.20→0.28 | 冰晶实体变粗、短暂碎冰反馈增强 |
| 绯梦弹 | 0.20→0.27 | 粉色光核变大，与三层印记后的大绽放分工 |
| 共鸣花种 | 0.20→0.26 | 花种主体成长，共鸣连接线保持细而清楚 |

五级等差成长；碰撞半径是世界单位，画面主体需按相同世界空间投影，不直接用屏幕像素宽度替代。派生子弹默认仅保留来源主弹55–65%的视觉/碰撞尺度，具体攻击已有专用大小时单独定义，不能让每枚小火种都膨胀成完整主弹。

#### 范围可信、反馈有力、危险可读

1. 火浪/水环/刃面等**表达伤害的实体边缘**与真实命中足迹一致，目标视觉误差控制在约10%以内；圆形范围与敌人碰撞半径的接触判定另算，不应被误判为超出特效命中。
2. 光晕、火星、雾气和尾迹可以超出实体边缘，但保持透明、逐渐衰减；它们不新增伤害，不承担范围指示。单次攻击的余波也不额外增加DOT。
3. 命中力量感优先用主体体积、扩张速度、短促亮度峰值、现有音效和敌人受击反馈。可适当延长装饰性消散，不用长时间高亮色块铺满屏幕。
4. 同屏叠加时，玩家轮廓、Boss冲锋长条、扇形预警、精英地震边界优先清晰。优先减少次要颗粒/内部雾气，不先把已获得的大范围攻击缩回去。
5. 收割段允许更密集的击杀反馈，让“变强”充分可见；Boss预警重叠时压低装饰性雾气/闪光的视觉权重。渲染可读性调整不改变伤害或模拟时钟。
6. 省电/低画质保留同样的攻击主体轮廓、命中范围和关键扩张动作，只削颗粒数量、雾气层数、尾迹采样；不能让低画质玩家看不到实际扩大后的范围。

#### 对平衡的处理

扩大范围本身就是升级收益。对上述攻击首版保持目标伤害和频率，不在放大同一时间叠加更多子弹、更多跳数和更长持续时间。密集低血敌场景允许出现更显著的覆盖提升；Boss仍是每次/每程原有命中次数，不能因火浪更大而重复扣血。

若群体输出超过预期，依次检查同目标去重、密度和派生触发，再考虑微调伤害或周期；优先保留已经建立的大体量与覆盖感。也不通过统一增加敌人生命把放大后的成长体验完全抵消。

## 4. 十种基础武器的目标数值

`g`为每次升级相对1级伤害的累加系数：`D(L)=D1×[1+g×(L−1)]`。下表伤害不含全局魔力、遗物、额外弹75%系数。间隔为该武器基础间隔，普通投射副槽再乘第3节系数。

| 武器 | 战斗职责 | D1 → D5 | g | 间隔L1 → L5/秒 | 基础覆盖与关键成长 |
|---|---|---:|---:|---:|---|
| 火花弹 `spark` | 稳定点杀、火系反应入口 | 18 → 29.52 | 16% | 0.44，保持 | 射程10.5；火花面积等级成长保持 |
| 水泡弹 `bubble` | 减速、湿润、持续追击 | 16 → 27.52 | 18% | 0.58，保持 | 射程10.5；速度×0.7；减速1.5–1.9秒 |

### 9.2 选卡规则

在现有三选一框架内调整供给，不新增锁定构筑功能：

1. 前三次升级，每次至少一个已装备武器强化或该武器可用支持卡；这三个候选中的支持卡不得连续三次都缺席。
2. 普通候选中最多出现一个未装备武器，减少三张都在换路线；有可强化内容时至少一个候选推进现有构筑。
3. 稀有概率仍从25%起、最高55%、6次未获核心可保底。保底集合要覆盖当前来源能触发的水/草/冰/粉/电/近战路线，不仅偏向火系连爆。
4. 核心候选按具体已实现条件筛选：火系可用殉爆/油壶，水系可用泡泡孢子/潮涌棱镜，草系可用遗嘱/湿藤；冰/粉色主投射物可用镜面/蜂巢，纯雷芽可用疾风共振/律动破阵。雷鸣中继现有获得前置要求投射物，不能只因名称带“雷”就塞给纯雷芽；条件不满足的候选不“保底塞入”。
5. 达成双武器融合或技能进化条件时保留可见入口。材料已消耗、技能满级、遗物已有必须排除。

这是候选保障，不是免费授予。玩家仍可选择生命或移速，也可主动放弃融合；不能把理论上可选的24点全部当作实际必然拿到。

### 9.3 商店和治疗

首轮暂保留现有经济数值：前五波固定奖励35/40/45/50/55，合计225；新武器35、普通技能25、遗物70、进化75；武器强化按现有等级计价；草场补给18金币恢复35，付费刷新5/10/15递增。

调整的是商品相关性：保留一个推进已有构筑的普通格；稀有格优先给当前可触发的机制，不提高稀有出现数量；缺血时保留治疗格。每次商店通常足够完成3–5次购买，具体要由真实赚币和刷新行为测量，不能预先注入金币达标。

不增加免费满血、无限治疗刷新或无尽专用复活。跨轮金币可保留，完整构筑后金币剩余不自动兑换成无限攻击力/生命。

## 12. 无尽：有喘息的逐轮上升，不复制首轮开荒

### 12.1 首轮与后续轮的区别

首轮使用上述闯关成长基础。无尽第5波的旗帜大波保留，但安排为**50–70秒短强压、70–80秒收束**，不把最后10秒全变成危险叠加；旗帜段背景5.2/秒、5秒请求F F T S、配额12/5/1。其他第5波阶段沿用第10节。

第2轮起前一轮构筑和生命保留，不再重演20秒空档式教学：第1波前20秒背景改为3.5/秒，前10秒仍不加危险护卫，让玩家展示新构筑。其余每波仍有至少10秒的明确释放窗口。

### 12.2 跨轮倍率提案

令`n=轮次−1`：

- 危险普通敌/精英生命：`H=(1+0.16×min(n,5))×1.08^max(n−5,0)`；非燃料普通怪还乘对应轮内波倍率，精英只乘自身480。
- 背景草团与晶屑作为燃料怪，轮次倍率为`H燃料=min(H,2.5)`。草团使用12/14/16/18/20/22基础；晶屑使用8×对应正式波倍率。不要先乘H再乘H燃料。
- Boss生命：`B=(1+0.28×min(n,5))×1.10^max(n−5,0)`，首轮6000。
- 接触伤害：`D=1+0.05×min(n,8)`，上限1.40；覆盖现有接触路径，不暗中扩到地震/弹幕伤害。
- 背景与护卫请求速率：`R=1+0.03×min(n,8)`，上限1.24；预警时间不除以此倍率。
- 总存活上限：`P=min(1+0.025n,1.15)`乘第10节每波上限，向上取整且不超过128。它不是再乘一次请求速率。
- 普通敌基础移动速度不跨轮上升；Boss预警/弹速/冲锋不无限加速。地震/弹幕等固定技能伤害首版保持，只有已明确列出的接触伤害增长。

这是从当前后期全部封顶改为“危险数量与伤害封顶、生命继续缓升”的方案。前几轮玩家仍能靠补技能和进化追上，完整构筑后才逐渐由持续输出/走位能力决定极限。

当前`spawnSwarm`会覆盖普通草团生命，覆盖后没有保留一般敌人生命倍率。上述燃料倍率是明确的拟实施规则：应在该覆盖之后应用一次，而不是只修改`ENDLESS_SCALING`便认为已覆盖草团。危险怪继续成长、燃料怪最高2.5倍，是为了深轮次仍能靠低血敌触发传播与拾取，而非全场变成肉墙。

生命增长不能直接判定可玩性。验收至少覆盖12轮；若同预算完整构筑的Boss战中位数超过120秒，先下调后段Boss每轮10%的指数增长，不通过取消喘息、缩短预警来补偿。实现时必须对倍率作有限数检查，防止极深轮次溢出。

### 12.3 规则和加时

沿用现有五种规则：疾芽先锋、岩甲列阵、孢子连锁、晶屑狂潮、携宝诱饵。第2–3轮1项，第4轮起最多2项；不新增独立玩法。

规则对危险供给的加强只作用于压力/中等段，收割期不新补疾芽/重甲/爆孢；类别上限和总上限仍有效。Boss波即使抽到孢子连锁，也不突破本方案“无导演爆孢”的限制。

携宝诱饵仍是既有一次尝试配额的补足：若某波本来已有携宝事件，不额外叠成两只。击杀Boss仍给60金币，继续下一轮；不会因取得奖励而免费满血。

Boss到90秒按原规则进入加时狂暴，不计作闯关失败；额外支援固定为最后一个收割配置，保持少量可击杀目标，不随加时每秒继续增量。实际死亡仍立即结束。

## 13. 三条可行路线与投入预算

下面是21–24次奖励的设计样例，不是商店/升级必定给齐的固定攻略；用于检查成长成本。起始武器自带1级不计一次奖励，获得新武器1级要计一次，合成选择也计一次。

| 路线 | 关键构成 | 应获得的体验 | 主要弱点 |
|---|---|---|---|
| 火系传播 | 火花/水泡合成蒸汽彗星，配横扫和少量连爆/燃烧 | 中期打通拥堵路线，收割段连锁爆发，Boss输出稳定 | 接近敌人、消耗湿润；不能同时无限触发全部反应 |
| 水冰防守 | 水泡＋霜晶，配回潮/震爆和一项防御遗物 | 冻结普通敌、控制群体节奏；对Boss靠水泡直击和往返伤害 | Boss免疫冻结，不能靠站桩不动通关 |
| 草粉传播 | 飞叶/共鸣花种＋绯梦或雷芽，配遗嘱/绯樱 | 穿透挂印、优先补刀引发传播，分散群怪有优势 | 需要已有印记和敌群；对单输出依靠主投射物 |

一套24次奖励的成本示例：火花3级＋水泡3级需5次，合成1次、强化融合到5级2次，共8次；横扫3级3次、雷芽1级1次，共12次；伤害2级、攻速2级、多重1级、生命2级、移速1级共8次，累计20；3件遗物＋冲击波1级共4次，合计24。

该例仅用于证明存在完整预算路径，不是通过率证明，也不要求每局三件遗物恰好齐全。水冰与草粉需要以同样24次投入预算测试；不能给它们偷偷多发5级技能后再宣称三路线平衡。

## 14. 实施顺序与验收

### 14.1 分批实施，不一次改完所有变量

1. **校正显示和结算边界**：融合升级前后值、额外弹快照、控制叠加、伴星/冲击波成长口径、临时增益详情，以及主体大小与命中范围共用数据。先保证数据可读、能统计来源。
2. **基础成长包**：10武器、投射副槽、经验曲线、前期候选保障；先不改44件全部事件逻辑。
3. **群体与协同包**：独立技能、融合、7进化、17件遗物调整、选定攻击的体量/真实范围成长和最终范围限制。保留未改27件，验证继承与事件预算。
4. **闯关导演包**：6波供给、危险配额、喘息和Boss参数；用真实连续整局观察成型与超时。
5. **无尽包**：跨轮倍率、规则在收割期的约束、加时供给；再做长局与手机验证。

每包都与上一包固定种子对比；不能把第1包发现的界面错误等到第5包再用加伤掩盖。

### 14.2 测试矩阵

| 维度 | 必须包含 |
|---|---|
| 起始幻兽 | 三种全部；相同拾取策略和奖励次数 |
| 战斗样本 | 单体普通、稀疏群体、密集低血群、岩甲混编、精英、纯Boss、Boss支援 |
| 成长策略 | 集中强化、控制/生存、融合、技能进化、普通非天胡混合构筑 |
| 操作 | 不移动对照、普通绕行、拾取走位、看预警变向；不可只测最优脚本 |
| 奖励随机 | 至少30个固定种子；每轮同时记录拒绝购买/预算不足，而不是强塞目标装备 |
| 场地 | 空场用于归因；真实固定地图与无尽障碍用于结论；小横屏视口必须单列 |
| 无尽 | 1/2/3/4/6/8/12轮；稀疏控制与高密度连爆两种极端 |
| 运行边界 | 暂停、重开、跨波精英、Boss死亡、经验触发升级、商店前置失效 |

### 14.3 达标指标和调参方向

| 指标 | 目标/触发复查的条件 | 优先调整什么 |
|---|---|---|
| 轻松段背景清理吞吐 | 稳态击杀背景数/实际背景入场数约1.3以上；可清理前段积压 | 先减危险残留，再检查可达经验；不先减背景草团 |
| 收割体验 | 进入释放窗口5–8秒后危险预警次数明显下降、经验可拾取 | 危险请求停止时点、精英恢复间隔 |
| 压力段 | 相邻同局30秒窗口的近身危险停留/受击明显高于收割段 | 危险组合和入口方向，不统一增加全怪血量 |
| 对王输出 | 同预算三起手成熟构筑至少各有正常通过90秒的非稀有依赖路线 | 命中兑现率、Boss系数、基础点杀 |
| 融合价值 | 同预算跨场景平均约15–30%；密集低血敌场景覆盖可高30–60%，对单仍按原命中次数 | 先看失去的材料机制/新增槽收益和范围兑现，再调D3 |
| 放大后的攻击 | 5级横扫、宽潮刃、融合爆发、梦印绽放有明显体量变化；真实覆盖与主体一致 | 检查实体边界、碰撞快照、同敌去重，不只看截图尺寸 |
| 预警可读性 | 568×320和844×390横屏下，大范围攻击叠加时仍看清角色、冲锋/扇形/地震边界 | 先削雾气和次要颗粒，保留攻击主体与预警 |
| 低画质一致性 | 与高画质相同命中结果、主体范围和关键扩张，只减少装饰 | 核对共享数值来源，禁止画质切换改变范围 |
| 遗物价值 | 普通有用遗物单件不稳定贡献超过总有效伤害30%；机制核心允许改变玩法 | 派生触发次数、根伤害基准、冷却，不统一降所有主武器 |
| 生命容错 | 100–140HP常规构筑可承受几次错误，但站桩仍会死亡 | 连续命中、受击保护和危险重叠；不先塞复活 |
| 无尽Boss | 普通合理构筑前几轮不大量超过90秒，完整构筑中位不超过120秒 | 跨轮生命增长和对王兑现率 |
| 性能 | 不突破既有池预算；弹池阻塞导致主攻击有效频率损失持续超过15%需复查 | 派生占用、排队和表现密度，不增加到无限弹池 |

这些比例是调参门槛与方向，不是尚未执行的测试结果。低血、低输出玩家仍可能失败；目标是保证可解释的挑战和可学习的反击窗口，不是保证任何随机选择都通关。
