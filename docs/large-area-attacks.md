# 大范围攻击实现与验收

## 游玩入口

正式闯关或无尽模式，在升级或商店获得「星陨爆发」「星雨弹幕」后自动释放。三种幻兽均可获得，不占普通武器槽，不修改历史模式的技能池。

## 判定与配置

实现集中在 `src/area-attacks.ts`，由 `Combat` 提供纯数值摄像机矩形、敌人和伤害回调；所有实际伤害进入 `damageEnemy()`。模拟不读取 DOM、纹理状态或 GPU 对象。

| 项目 | 默认规则 |
| --- | --- |
| 星陨爆发 | 每 12 秒；预警 0.45 秒；基础伤害 85，每级增加基础值的 25%，共 3 级 |
| 全屏范围 | 爆发瞬间快照未震动摄像机的地面矩形；敌人地面中心在矩形内，边界包含；排除未出生、死亡目标；穿越障碍 |
| 精英 / Boss | 分别受到 70% / 40% 伤害，在 `AREA_RULES` 配置 |
| 爆发去重 | 每次 cast 独立记录敌人唯一 ID，扩张和淡出不再造成伤害；同次爆发先结算非 Boss，最后结算 Boss，避免胜利清场吞掉其他击杀奖励 |
| 星雨弹幕 | 每 5 秒；环形、120° 扇形、交叉轮换；等级对应 12 / 18 / 24 道，1 / 2 / 3 轮；轮间隔 0.12 秒 |
| 弹道 | 速度 24，飞行时间 1.8 秒，扫掠碰撞；每道最多命中 3 个目标，伤害依次为 100% / 80% / 64% |
| 弹幕去重 | 所有轮次共享 cast 命中记录，同一目标同次施法仅直接命中一次；整次施法最多 72 个目标 |
| 协同 | 继承当前主武器来源，复用殉爆、荆棘遗嘱分裂、泡泡孢子弹射等适用规则；不把新技能当成普通主武器施法来复制 |
| 协同上限 | 每次大范围施法及其后代共享最多 24 个排队反应节点、每目标最多 2 次总伤害、最多 256 个目标记录；原有代数、每步派生数量、弹射和普通弹池预算继续生效 |

「同次直接攻击仅命中一次」和「整条协同链最多命中两次」分别控制直接伤害与派生伤害。二者均不依赖画质。

## 容量与降级

- 爆发模拟池 2 次，独立视觉通道仅显示 1 次；同时存在两个爆发时，第二次可以省略视觉，但伤害照常结算。
- 弹幕施法池 4 次、独立弹道池 96 道；接受施法时一次性预留全部轮次。满池拒绝新请求，自动施法等待容量，成功接受前不消耗冷却。不会部分发射后扣掉整次冷却。
- 普通投射物池仍为 24。弹幕用 2 个共享 InstancedMesh 批次绘制，核心和尾迹各最多 96 个实例。
- 爆发视觉最多 32 个碎片；低画质减至 8。弹幕低画质关闭尾迹，保留所有核心和判定。
- 大范围死亡淡出池 256；耗尽时替换最早结束的记录。现有经验球满池合并、金币和击杀奖励逻辑保留。
- 所有新增视觉预创建且可清理、释放。爆发使用基础几何，不需要纹理加载成功。普通命中特效仍走现有可读性裁剪。
- 8 连斩起显示 1.35 秒提示和 0.24 秒轻微震动，复用有界音效系统。反馈不更改攻击计时和命中范围。
- 声音反馈按真实击杀累计：0.65 秒连续窗口内达到 3 / 8 / 20 杀，播放逐级增强的冲击与奖励泛音。持续击杀保持节奏脉冲，不逐敌叠音；按音频实时时钟限频，最高 8 个效果声源。星陨爆发使用独立的低频、碎裂和星光层；弹幕连杀在实际击杀时反馈，不等弹道结束再补一次爆炸。重音期间背景音乐短暂降低，静音和暂停清理声源及连杀音频状态。
- 暂停、后台与升级沿用固定步冻结；死亡、场景清理和重开释放新增攻击与死亡记录。画质只影响装饰。

## 验证记录

新增 9 项模型测试和 1 项浏览器渲染/生命周期/压力测试，在 Chromium、WebKit 共 20 项通过。另执行核心战斗、升级、遗物、武器融合和历史挑战的针对性回归：57 项通过，1 项已有失败。

已有失败位于 `tests/challenge-model.spec.ts:63`：仍断言圆形边界距离不超过 10.95，而 main 已采用矩形边界。用 HEAD 原版 `combat.ts` 重跑该测试，得到相同的 11.191134165412905 失败值；未修改该无关测试或战斗边界。

`npm run build` 通过，保留原有 Three.js 大 chunk 提示。没有运行整个测试集，没有手机真机测试。

音效增量验证：`tests/combat-audio.spec.ts` 在 Chromium 的 6 项检查通过，包含实际 24 敌爆发触发、持续连杀、密集调用限频、静音与暂停。Windows 自动化 WebKit 未提供 AudioContext/webkitAudioContext，播放验证标记为跳过，不视为通过。`artifacts/harvest-audio-preview.wav` 为五秒合成试听片段，依次示例普通命中、小连杀、大连杀、爆发及持续割草；它不是整局录音，试听片段采用独立预览音量，游戏仍使用现有总音量与压缩器。

浏览器压力场景使用 96 道弹幕、256 个敌人，测量 50 个固定模拟步骤；数据在 `artifacts/large-attack-pressure-{chromium,webkit}.json`。记录 CPU 耗时、绘制调用及几何/纹理数量，确认低画质不改变模拟、暂停冻结、清理和资源数量稳定。该测试并非整局最坏负载或手机 GPU 帧率测量，不代表真机性能结论。

复现命令（PowerShell；独立端口避免误用其他项目的开发服务器）：

```powershell
$env:MONSTERBONK_TEST_PORT = '5187'
npx playwright test tests/area-attacks.spec.ts tests/area-attacks-ui.spec.ts
npm run build
```
