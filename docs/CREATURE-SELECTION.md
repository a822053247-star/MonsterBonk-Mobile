# 主菜单幻兽选择

主菜单新增「选择幻兽」选项，三张卡分别展示焰绒、泡泡螈、芽刺兽及其攻击特点。选择后点击面板内的「开始挑战」直接出战；主菜单的「开始挑战」同样使用当前选择，默认焰绒。关闭面板只保留选择，不自动开始。

每局只有所选一只幻兽，一个摇杆移动、自动攻击与升级随机三选一。复用已有三物种动画、基础攻击和对应融合卡池，没有新增战斗系统或技能按钮，也没有新增有限波次或胜利条件。水草角色显示正式物种名称和基础攻击，不再显示“开发验证”。

重开保留本次物种并重置技能；返回菜单可以换兽。旧三兽编队固定三成员，其他历史模式保持原有焰绒。`fusionDev` 参数仍能预选角色，但手动选择优先，不再要求玩家使用开发链接。

选择面板支持触摸、键盘焦点、Escape 关闭，选中状态使用 `aria-pressed` 表达；打开时主菜单设为 inert，关闭后焦点回到选择按钮。三张角色图片在打开面板时才加载，使用现有静态 PNG，没有修改原素材。

新增五项浏览器测试通过真实主菜单逐一选择三种幻兽，检查单成员、攻击类型、自动发射、卡池和重开；另检查关闭不开始、URL 预选被手动选择覆盖、兼容模式与再次进入的选择保留。844×390、568×320 含安全区域布局均验证触摸目标可点击，真实截图在 `artifacts/creature-selection-844.png` 与 `artifacts/creature-selection-568.png`。
