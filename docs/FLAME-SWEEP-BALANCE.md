## 战斗规则

- 横扫仍自动锁定附近敌人，每次挥击即时结算一次扇形命中；方向在该次攻击内固定。
- 火环从4级开始独立计时，在角色当时的位置即时结算一次整圆伤害；不需要面向目标或按键，不依赖挥击是否就绪。
- 火环视觉固定在施放地点播放0.55秒；玩家走动后，下一次火环从新的位置施放。渲染不会再次结算伤害。
- 两者不占子弹槽，弹池满时照常工作；分枝、分裂、连锁不会复制横扫或火环。
- 范围升级及过载核心同时作用于两者，最终半径上限分别为6/6.5，保留远程射程优势。过载核心对近战构筑开放，仍有20%周期惩罚。
- 通用伤害、武器等级、专精徽记、潮汐遗珠和攻速按现有规则生效。横扫等级升级及攻速变化保留当前冷却的完成比例；火环从4升5也保留进度。
- 火环第一轮等待完整周期；暂停、升级选择及死亡冻结计时。跨波、回菜单和重开清除火环，下一波不会立即兑现上一波蓄积的火环。
- 火环与横扫都尊重实心遮挡、出生保护和统一击杀/金币/经验/Boss死亡流程。

## 可复现平衡探针

运行 `npm run balance:weapons`，结果写入 `artifacts/weapon-balance-results.json`。覆盖4武器×3等级×5场景×2套强化预算，共120组，每组24秒、60Hz，调用真实Combat逻辑。

探针隔离一件主武器、固定敌人位置并禁用经验选项暂停，用于比较角色定位。近身首领距角色2，远处首领距角色8；穿透场景是从4.5起每隔1.4排列的6个目标；清杂场景是持续补充的24只22血敌人环绕角色。两次额外强化分别使用：火花分裂+分枝、水泡扩散+连锁、飞叶分裂+连锁、横扫伤害+攻速。

满级、无额外强化的实测结果：

| 武器 | 近身首领DPS | 远处首领DPS | 排列目标总DPS | 远处单目标减速覆盖 |
|---|---:|---:|---:|---:|
| 火花弹 | 72.90 | 71.55 | 71.55 | 0 |
| 水泡弹 | 42.75 | 42.75 | 42.75 | 98.4% |
| 飞叶弹 | 52.80 | 51.60 | 157.20 | 0 |
| 火焰横扫 | 80.39 | 0 | 107.19 | 0 |

满级、各投入两次额外强化时，近身首领DPS为火花145.80、横扫111.05；24秒持续贴身杂兵压力下击杀数为横扫1047、火花441、水泡383、飞叶110。横扫明确领先近身清杂；火花有更高的成型单体输出和远程安全性；水泡承担持续减速和扩散控制；飞叶依靠远距离穿透处理队列。

自动平衡约束覆盖1/3/5级：横扫基础近身首领输出在火花的75%–115%之间；成型单体输出低于火花；8单位外横扫输出为0；基础飞叶对列输出高于火花40%以上；水泡远处单体减速覆盖超过95%；横扫成型贴身清杂为成型火花的1.5–3.5倍。

这是固定压力场景下的相对预算，不是通关率或实机帧率结论。生存、地图障碍、移动策略和玩家操作仍会改变收益；没有声称所有场景DPS相等。火环使用现有火焰图集与32处边缘火舌，图集缺失时使用有界程序化回退。后续[现有素材特效升级](FLAME-SWEEP-EFFECTS.md)保持本页战斗参数不变。
