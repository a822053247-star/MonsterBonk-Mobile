# 中后期构筑连锁与特效预览（1.8.0）

日期：2026-10-21。分支：`codex/local-work-20261021`。基于 `7eec95850e5e979f2da633072cb47a3b67254c24`，本次改动尚未提交。

## 玩家体验

- 升级至少提供一张推进已装备武器/对应融合的普通卡（存在合法候选时）；稀有概率触发后真实保留展示位。连续六次抽取未取得核心遗物时，保底展示一件适配核心。玩家可以拒绝；购买或选取核心会重置计数，不保证指定配方。
- 殉爆在三级火花+命中分裂，或三级横扫时觉醒。首代按原始攻击快照65%计算，后续每代保留85%，最多三代；成熟燃烧击杀也能接续。未觉醒规则继续沿用。
- 新遗物 `draft-boiling-core`（沸腾核心）：装备水泡与火系武器后可获得。水泡施加2.4秒湿润，火系非燃烧命中消耗湿润，触发半径2.5×源范围倍率、原始攻击快照65%的蒸爆。同一目标冷却0.6秒；蒸爆不再触发蒸爆，火系击杀可继续殉爆。
- 沙漏和施法节拍同时推进武器冷却与串行发弹节奏，仍每tick最多一枚真实远程弹。HUD/暂停/结算显示共鸣，结算显示连锁击杀与蒸爆次数。

## 事件与预算

`combat-reactions.ts` 集中定义成熟条件、伤害衰减及节点预约上限。原始伤害/成熟状态在施放时快照，回声先乘50%且保留前次施放的成熟状态；升级不改写在途施放。弹体分裂代数与来源传播代数分开。

成熟殉爆/蒸爆每原始来源最多预约24个节点、传播深度最多3。成熟殉爆延迟65ms形成可见接力；每tick消费至多32个已就绪事件，已接受伤害延期不丢。旧未觉醒遗物保留原有大队列延期行为。所有伤害、唯一死亡、金币、经验与Boss胜利仍通过原 `damageEnemy`。

24弹体、48效果与256敌人对象池不扩容。关键爆发优先复用命中/拾取/死亡的表现槽；缺少表现槽不影响伤害。前四波继续无缝衔接，第五波后唯一商店、暂停/升级冻结、死亡和Boss胜败优先级保持原流程。
