# 永恒雪原：无尽新地区设计 V1

日期：2026-10-24。状态：**第1–6节为原始设计；首版已按用户素材接入代码，尚未运行验证，实际范围见第7节**。

本次仅新增设计文档。依据当前工作区源码、已有测试及地区接入约定；保留既有未提交改动。本文的尺寸和布局是拟实施目标，不是现行参数或实测结论。

## 1. 核心体验

**在宽阔的蓝灰冰原上聚拢敌群，绕过短雪脊改变追击方向，再从另一侧返回拾取。**

永恒雪原是无尽的第三个地区，建议 ID 为 `snowfield`。不是封闭关卡，也不重做闯关地图。地区差异来自空间组织：草甸自由散绕，遗迹沿贯通石路穿行，雪原围绕短而弯曲的障碍岛完成较大的回转。

第一版让玩家一眼认出雪地，同时保持单摇杆的直接操控。雪地与冰面均正常行走；不加入打滑、寒冷条、暴风雪遮屏、地面伤害、元素增伤或地区敌人倍率。白色冰面裂纹仅为装饰，不代表坠落或伤害。

### 选路卡文案

- 名称：永恒雪原
- 地形短句：开阔冰原 · 弧形雪脊
- 描述：穿行雪脊两侧，在宽阔冰原回转，寻找绕回拾取的路线。
- 宝箱说明：封印宝箱优先通用强化；数量不变。

奖励倾向沿用已有 `growth`。地图辨识度由地形提供，第一版不创建冰系专属奖励池，不承诺必出移速、防御或冰系道具。

## 2. 空间布局

继续采用当前 **64×64 世界单位分块**。以下尺寸均为世界单位；通路宽度指两侧碰撞边缘之间的净宽，不是贴图间距。

| 地形单元 | 建议规格 | 作用与限制 |
|---|---|---|
| 冰原开敞面 | 每个32×32宏单元中心保留半径9的无障碍区 | 提供转身、拾取和阅读预警的空间；不是独立Boss场地 |
| 短雪脊岛 | 每宏单元最多1组，长度8–12、厚度2–3 | 轻弧形或斜向短脊，两端开放；不能围成U形口袋 |
| 外侧绕行带 | 雪脊两侧均可绕过，主要通路净宽至少8 | 形成不同绕行方向，不把玩家赶进单出口窄口 |
| 次级缺口 | 如出现两组相邻障碍，净宽至少6 | 供临时换向；不允许相邻组连接成横贯分块的墙 |
| 孤立覆雪岩 | 每宏单元最多2块，碰撞半径0.7–1.1 | 打断空旷地平线；不放在绕行带、缺口和中心开敞面 |
| 雪松与细碎装饰 | 雪松只在脊背外侧少量布置；枯草、碎冰无碰撞 | 辨识方向；避免连续树墙和遍地碰撞点 |

这些是初始布局上限，不是每块必须填满。候选不满足净宽或安全区时直接省略，不持续随机补点直到塞满。

### 平面关系示意

```text
             通往相邻开敞面（净宽≥8）
                        ↑
          覆雪岩        │        少量雪松
                        │
    ←─────── 开敞冰原：中心半径9 ───────→
                 可回转、读预警
                        │
             ↙          ↓          ↘
         左侧绕行     短弧雪脊     右侧绕行
             ↘       两端开放      ↙
                  下一片开敞面
```

示意描述相邻空间关系，不要求所有宏单元使用同一朝向。用种子决定雪脊朝向、镜像和少量偏移；主开敞面和连接走廊先确定，再放装饰。

### 可复现生成约束

1. 以世界坐标上的32单位宏网格划分单元；同一种子及宏坐标决定布局，不受分块访问顺序影响。
2. 每个宏单元中心与四条边中点之间保留净宽8的连接带；相邻单元使用同一接口，保证连续的通行骨架。雪脊只能放在连接带之间的角部，必要时缩短或取消。
3. 中心开敞面、连接带和出生安全区优先级高于雪脊；所有碰撞体和高大装饰均须避让。
4. 原点沿用至少半径8的安全留白；切区可能发生在任意坐标，仍须使用现有迁移流程，不能只验证原点出生。
5. 以实际障碍半径外扩玩家碰撞半径0.62检查通达性；另以当前源码中的精英/Boss足迹检查狭口，不能仅凭玩家可通过便宣称Boss可通过。
6. 雪脊用少量相接圆形碰撞体形成短轮廓；美术按相同基底分段，冰雪外沿允许小幅无碰撞软边，不画整片实墙却只放几个稀疏碰撞圆。
7. 各物件由单一宏单元归属，碰撞与可见基底均留在所属分块内；不依赖相邻块装载后才补全墙体。地面颜色与裂纹使用世界坐标采样，边缘连续。

## 3. 视觉设计

氛围为寂静、辽阔、长期冰封，保留当前像素素材与2.5D角色比例。以低对比地面承托鲜明角色和技能，不用满屏纯白制造“雪感”。

| 层级 | 建议配色/表现 | 可读性要求 |
|---|---|---|
| 主雪地 | 冷灰白 `#C7D5DB`，少量浅蓝阴影 | 减少高频纹理，亮点不覆盖整个地面 |
| 冰原 | 雾蓝 `#91AFBF`，不透明、低反光 | 冰面和雪地都可行走，边缘无危险闪烁 |
| 雪脊 | 深蓝灰基底 `#536C7A`、浅色雪帽 | 明确实体轮廓，和可走浅雪区别 |
| 地标 | 暗青雪松、倾斜冰岩、矮冰簇 | 不使用宝箱/祭坛相似轮廓暗示虚假交互 |
| 氛围 | 稀疏小雪粒、很淡的远景冷色 | 低画质可关闭；预警和角色前景不得被遮蔽 |

首版不增加实时镜面、动态积雪或全屏雾。冰面颜色变化烘焙进地形，雪粒复用固定预算；暂停冻结，重开重置。天气表现不参与碰撞和战斗随机数。

高物件沿用遗迹的角色遮挡淡化思路，只改透明度，不改变碰撞与导航。确认红色冲锋、扇形和地震边界在雪底清晰，也要检查蓝色水/冰技能不会与冰底融成一片；优先降低地面亮度和纹理对比，不给所有技能另做雪地版本。

### 素材范围

仓库已有 `public/assets/world/Tileset/` 下的 Snow 地面及装饰候选，但本次未逐张做视觉检查，不视为已完成素材适配。

实施前检查现有素材的像素密度、透明边缘及可拼接性。最低需求：雪/冰地面各1套；雪脊直段、弯段、端部；覆雪岩2种；雪松2种；低矮碎冰与枯草。优先共用透明图集、最近邻采样和实例绘制。缺失项单列美术需求；程序几何回退可用于观察，不作为最终美术验收。

## 4. 战斗、事件与平衡边界

本地图不新增敌人、武器、遗物或Boss，不修改当前出怪名单、攻击循环、波长、跨轮倍率、经验、金币或商店。已有霜绒兽仍按实际导演名单出现，雪地不自动增加其数量或滑冲速度，也不赋予额外冰面减速。

沿用封印宝箱、失落工坊和元素祭坛的既有出现规则、奖励及失败条件。封印宝箱的地区偏好仅用 `growth`，无合法偏好时走现有合法奖励回退；不影响Boss宝箱。

事件选址要检查交互点周围的可达空间。封印宝箱离开半径当前为7，活动区若被雪脊切断会造成意外放弃；优先选择开敞面，空间不足则跳过候选。祭坛沿用当前临时占地清理与恢复流程，不能另造一套视觉清理但保留碰撞的规则。

已阅读 [平衡设计V1](BALANCE_DESIGN_V1.md)。采用其中关于预警可读、危险组合与可用空间的设计原则；其中范围、伤害、控制和导演调整仍为提案，本地图不一并实施。

平衡目标是**同一构筑面临不同绕行选择**。地形不能稳定提供无风险卡怪点，也不能靠长墙将移动躲避变成死局。若雪原难度明显上升，先减少雪脊长度/密度、扩大连接空间；不临时削弱该区敌人或增加补偿收入。

## 6. 交付预设与验收

拟新增预设：`region-snowfield`（自由观察）、`region-snowfield-combat`（实战）。现有 `region-choice` 扩展第三选项，无需另写模拟选路。固定种子建议 `snowfield-showcase-v1`；同图观察/实战切换及重开保留种子，重置本局资源。

实施当次应提供以下手动步骤；**以下均为待验证项**：

1. 观察：出生附近即可看到冰原、雪脊和雪松；绕雪脊两端走一圈，确认碰撞贴合、没有隐藏墙或U形陷阱。
2. 生成：固定/随机切换，穿过正负坐标分块边界、远走返回；核对同种子同布局、无地面接缝、无重复障碍、通路不断。
3. 实战：分别用火、水、草起始幻兽；经历追击、拾取、精英预警与Boss，重点看雪脊是否使冲锋/地震成为不可躲组合。测试预设不证明正常开局的整局平衡。
4. 事件：在雪脊附近布置封印宝箱并完成/放弃，检查通用强化偏好和奖励次数；另核对工坊及祭坛占地恢复没有卡住角色或掉落。
5. 选路：从草甸/遗迹进入雪原，再离开或继续雪原；在远离原点处切区，检查落点修正、状态保留、下一波只推进一次、重复点击无效。
6. 生命周期：加载中返回菜单、暂停/恢复、重开、更换项目；旧区块不能迟到覆盖新地区。资源失败需可识别并能退出。
7. 小屏/低画质：568×320与844×390横屏检查三张地区卡、角色遮挡和红/蓝预警；关闭雪粒后轮廓、碰撞、通路和命中结果一致。
8. 隔离：观察不刷怪；实战测试不写无尽纪录或永久捕捉；退出测试后的正式局恢复普通资源与出生规则。

当前扩展阶段按 [无尽扩展计划](ENDLESS_EXPANSION_PLAN.md) 的既有约定不运行自动化测试、平衡脚本、类型检查、构建或浏览器验证。后续若恢复自动验证，应扩展 `tests/infinite-world.spec.ts` 覆盖雪原的确定性、连接净宽和分块边界；该文件现有草甸断言不能当作雪原验证结果。渲染、选路、迁移和资源回退需各自验证，不以单个生成测试代替整条流程。

本次完成的是源码约束核对和设计文档；尚无雪原游戏截图、性能测量或平衡实测结果。

## 7. 首版实现交付（2026-10-24）

用户授权开始实现，并提供16种冰雪场景素材，要求全部作为障碍物，参考第一张繁花草甸地图。首版采用独立晶岩/覆雪岩岛与宽阔连通空间，未实现原提案中的8–12单位连续弧形雪脊，也未加入雪松、天气粒子或专门Boss空场；避免将当前素材拉成长墙。以下记录覆盖第1–6节中相应拟实施内容。

- `snowfield` 已加入地区注册与正式Boss后选路，普通默认地区沿用草甸；三张选路卡均可访问，小屏纵向滚动。
- 地形沿用草甸的世界坐标噪声思路，独立绘制连续的雪地、柔和雪岸、蓝灰冰面和稀疏风蚀细纹；没有棋盘格铺砖、打滑、减速、寒冷伤害或新增敌人倍率。
- 每64单位块最多16个障碍候选，按种子抖动、缩放及省略；所有16种素材都有实体碰撞，包括冰池与低石台。32单位宏网格保留净宽8的十字连接带，原点保留至少8单位安全区。不是原提案的每宏单元中心半径9空场。
- 主线程/Worker共用生成器，原64单位块、缓存、加载门禁、逐帧安装和版本取消继续使用；图集共用实例绘制，前景遮挡降至22%透明度，碰撞不随之消失。加载失败使用原有程序晶柱作为布景回退，最终美术验收须确认正常图集加载。
- 雪原封印宝箱偏好 `growth`，没有额外奖励、专属池或新事件。选路token、落点迁移、生命/构筑保留继续使用既有流程。
- 测试注册 `region-snowfield` 与 `region-snowfield-combat`。固定种子复用全地区的 `region-showcase-v1`，同图切换保留种子；退出测试继续隔离纪录和永久捕捉。

### 手动体验入口

1. 主菜单 → 新功能测试 → **永恒雪原·自由观察**。查看雪岸与冰面，靠近岩石/冰晶检查碰撞和遮挡淡化；冰池也应阻挡移动。
2. 点击切换随机地形，远走并穿越分块边界；点击固定地形回到可复现布局。点击开始实战，确认仍为雪原及相同种子；切回自由观察应停止出怪并重置测试局。
3. 进入 **永恒雪原·实战**，体验自动攻击、绕障和拾取；放置封印宝箱，确认实际奖励与通用强化倾向。
4. 进入 **Boss后地区选路**，完成真实宝箱结算后选择永恒雪原；加载完成进入第7波。重开可选择草甸、遗迹或雪原，检查小屏三卡滚动。
5. 分别检查暂停、重开、返回菜单，以及在远处切区后的落点迁移。测试局不应增加正式最佳纪录或永久捕捉。
