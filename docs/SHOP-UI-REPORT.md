# 第三阶段：森林魔法商店

## 改造范围

草场商店接入现有 `shop/shop-panel.png`、`shop/item-slot.png`、`shop/health-potion.png`、`shop/refresh-rune.png`、`common/coin.png`，奖励插画复用已规范化的技能和稀有道具显示素材。使用统一商品卡框，标题、插画、效果、代价、价格、购买按钮各有独立区域；名称、数值和文字均由代码绘制。

新增 `src/shop-art.ts`，从真实 ShopItem.kind、skill、title 及现有技能定义解析插画和商品类型，不再根据槽位下标猜测“武器／稀有道具／补给”。已购买商品退出可选池后仍可根据原商品ID找到插画和稀有度，保持原始价格可见。

## 保留行为

- `src/shop.ts`、`src/run-flow.ts`、`src/game.ts` 无本轮改动，价格计算、购买、治疗、刷新、状态机、输入处理和下一波逻辑保持原样。
- 保留 data-buy 与 data-shop-token、原事件委托和过期token校验。
- 金币不足、已购买、无适用商品均真实禁用按钮；金币、生命和刷新成本实时更新。
- 购买使其他商品失效时，以最新 ShopItem 集合重新渲染；已售槽位保留。类型从原商品判定，购买新武器后不会把已售卡误标为强化商品。
- 进入新商店或刷新后列表回到顶部；普通购买保留滚动位置。这只影响展示，不改变商品或交易数据。
- 图片加载失败保留CSS羊皮纸底、原图标、价格和按钮，图片不参与购买启用条件。

## 横屏适配

常见横屏采用四列，较窄屏幕采用两列局部纵向滚动。面板、滚动区域与操作栏分别布局，尊重安全区，下一波与刷新按钮保持可见。保留场景并适度暗化、模糊。

## 标题与信息精简

商品标题改为与升级卡共用的动态弧形文字，贴合商品槽位的羊皮纸标题带，长标题自动缩小。隐藏重复的休整小标签、减少信息条底色，价格保留清晰的独立小标签。game.ts 仅两处商店提示文案缩短为“已购买”和“本波奖励 +N 金币”等；交易、暂停和状态机逻辑未改变。商店及升级美术回归16项通过。

四角文字布局进一步修正：装饰面板独立为 `.shop-display`，只围住商品区；商店标题、金币和生命集中到框外顶部中间，刷新／菜单／下一波集中到框外底部中间。原四角不再承载文字或按钮。窄屏安全区检查同时断言上下操作栏不与装饰面板相交；本轮8项商店及完整流程回归通过。

购买区进一步统一为单行羊皮纸按钮：左侧金币图标与真实价格，右侧购买／金币不足／已购买状态。整条区域可点击，价格文字不拦截指针；移除原上下叠放的独立价签及绿色按钮，保留同一交易按钮与原令牌校验。空商品只显示居中不可用状态。
