# 无尽草场：流式无限地图（P0–P2）

新增独立菜单入口「无尽草场 · 无限探索」，保留「随机草场冒险」、融合六波、试炼等旧入口。此模式不设圆形地图限制，玩家继续使用摇杆/方向键移动与自动攻击。

## 地图技术

- 每个区块 64×64 世界单位，按玩家位置维护 3×3 活动集合。移动到新中心区块后，复用旧区块、释放移出的实例渲染缓冲，并创建新区块。最多 9 个活动区块。
- 固定种子 + 二维区块坐标生成树石与小池塘。渲染仅使用现有草地、沙地、水面和树石图集；共用纹理、材质、几何体，不为每个区块制作独立的大地面纹理。
- 初始出生区域半径 9 保持安全，区块边缘留空；主要通路按中心行列预留，树石与池塘碰撞源数据相同。负坐标使用 Floor 转换，不会错位。
- 原有地图的 `?world=fixed`、`?world=legacy`、`?seed=...` 保留；`seed` 对无尽模式决定所有区块的布局。重开保留种子，从菜单新出发换种子，固定 URL 种子不会变。

## 战斗集成

- 无限模式不再将玩家和敌人夹在以 (0,0) 为中心的圆形范围内，刷怪点改按玩家附近的局部地图通行性判断。
- 敌人导航仍复用 `GroundNavigation` 的 bounded BFS，但导航中心随着玩家移动；地图换块时用版本号失效旧缓存。
- 超过玩家 46 单位的普通场景敌人直接回收，超过 48 单位的经验球释放池槽，避免移动久后无限堆积。不提供离屏击杀奖励。
- 保留既有摄像机、战斗升级、对象池、帧率自适应及失焦暂停。

## 设计边界与后续

这是可玩的基础流式无限草场，不包含不同 Biome 之间的美术渐变、跨区任务、稀有蛋/祭坛事件，以及超长时间的浮动原点。其他模式维持原有的有限地图。

运行 `npm run build`、`npx playwright test tests/infinite-world.spec.ts tests/infinite-world-ui.spec.ts --project=chromium` 验收种子确定性、正负坐标跨区、九宫格数量及旧模式回归。请额外在手机真机做长时间移动与性能测试。
