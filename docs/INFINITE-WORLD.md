# 无尽草场：与「开始挑战」一致的六波玩法 + 无限像素地图

**玩法一致，只有地图无限。** 菜单「无尽草场 · 无限探索」与「开始挑战」使用相同的：

- 出战幻兽选择及逐帧像素形象、自动攻击、武器槽与融合构筑（`fusionEnabled` + `RunBuild`）；
- 正式六波 `RunFlow`，原有杂兵 / 特殊敌人 / 第 4 波精英 / 第 6 波 Boss、胜败结算；
- 正式的升级三选一、金币结算、第五波后的商店、购买与刷新流程；
- 摇杆/键盘操作、人物动画、战斗音效、固定步长、暂停与画质选项。

这仍是正式**六波挑战**而非无限循环刷波；“无限”指可以不停朝任何方向移动的**地图空间**。

## 为什么旧无限地图显得模糊

旧实现把一张原始 Grass 图片只重复 4 次后铺满 64×64 单位，导致单个原画像素被放得很大；树石精灵还没有应用裁剪图集的宽高比例。

现在复用现有 `src/world-sample.ts` 的 `PIXELS_PER_UNIT=16`、`pixelTexture`（NearestFilter、禁用 mipmap）、`crop` 图集提取，使用「开始挑战」本身的 `Grass.png` / `Dirt .png` / `Sand.png` / `Water.png` / `trees.png`。

- 每个 64×64 区块绘制原生 **1024×1024** 像素的 CanvasTexture；以原像素比重复草皮，不拉伸图块。
- 泥路继承样板的 4.8 单位宽、颜色和三层笔触；每块中央十字路口略带转折，相邻区块的四条道路在边界无缝连通。
- 池塘沿用与样板相同的逐像素行绘制沙滩、水缘与水面，并让碰撞物避开中心道路。
- 树木、岩石沿用相同图集裁剪和 `高度 × 原宽高比例`。跨区可复现；单组 InstancedMesh 批次减少 draw calls。

## 区块、导航与资源

- 每个区块 64×64，始终只保留玩家周围 3×3 个区块。离开视野的区块进入**九槽循环资源池**，复用原有地面 CanvasTexture、材质、场景节点与 InstancedMesh 缓冲，只重绘地形并重设实例矩阵，不在跨区时销毁再分配 GPU 对象。关卡真正关闭时才 dispose。
- 地图以种子 + 整数区块坐标确定。中心出生区域留空；支持负坐标，`?seed=forest-42` 固定布局。
- 复用敌人局部 `GroundNavigation`，玩家和敌人不再受原半径 33 的世界圆限制；远离玩家的敌人、经验球回收到对象池。
- 对比原来的一个 2048×2048 大地图，当前最多九张 1024×1024 RGBA 地面纹理，峰值纹理像素约 9M（约 36 MiB，不含 WebGL 额外开销）；注意移动设备实际 GPU 内存、浏览器 Canvas 副本与跨区帧时间。
