# 像素草场与受约束随机

2026-10-19：已完成固定样板、移动战斗验证及受约束随机。主菜单选择「随机草场冒险」启用；仅保留焰绒单兽移动和自动攻击，两位伙伴不再生成或跟随。单兽回归、犄角试炼、三波闯关和菜单保留原地图。`?world=fixed` 使用第 2 步固定样板，`?world=legacy` 回退旧地图；新地图任意必需图片加载失败也会整体回退，避免出现看不见的障碍物。

## 已实现

- 中央半径 8 单位内无障碍；4.8 单位净宽泥路连接东西南北，路面及侧向空间均在可活动边界内。移开北路挡路树和东侧成对石头，树石按固定群落放置。
- 池塘带沙岸，以相交圆形成略不规则轮廓。固定样板的池塘在右侧，随机模式的位置随种子变化。水面和碰撞来自同一组参数，主控、敌人出生与弹体检测共用障碍列表。
- 地面使用 `public/assets/world/Original Textures/` 的草、泥、沙、水；树和岩石从 `Tileset/Decorations/trees.png` 按 32×32 单元切分。移除了误从变体图集中裁出的微小树木碎片，不再将其当作草丛摆放。原 PNG 不修改。
- 保留固定 45° 正交镜头。树石面向镜头、脚底锚定地面，保持图片比例；主控附近可能遮挡角色的树淡化，并关闭深度写入。
- 地面一次烘焙为 2048×2048 纹理；使用最近邻采样、共享贴图与几何体。草地降低对比度，不新增实时阴影或逐帧地形生成。

敌人路径与出生：样板使用共享的 1 单位网格路径场，按最大敌人体型保留净空，禁止穿角；目标换格或切换地图时更新。视线畅通时直接追击，否则沿安全路点绕行；保持原敌人速度、伤害和接触规则。出生位置检查边界、障碍净空、与已有敌人的距离及连通性，保留 0.75 秒预警。随机 24 次失败后使用有界角度/距离补选；无合法位置或对象池已满则等待下次生成。

根因记录：旧局部切向绕障在重叠水域边缘会相互抵消，32 条池塘追击路径中有 2 条在 45 秒后仍距玩家约 13.8 单位。保留原碰撞修正，替换样板模式的引导方向后复现消失；旧模式继续使用原转向。额外的坦克长时间测试需要处理升级选卡暂停，否则会把正常暂停误判为卡住。

## 受约束随机与种子

- 中央半径 8 单位保持无障碍，原有东西南北主路保持 4.8 单位净宽。外围四个区域槽位随机分配林地、岩石区、池塘或空地，并对位置、树型、树石数量及水岸朝向作有界变化。每张随机地图有 1–2 处池塘，不把景物均匀撒满整张地图。
- 树石之间预留至少 3.2 单位间距，池塘边也保留绕行空间。生成器先排除侵占出生区、道路或活动边界的位置，再用实际敌人导航的 1 单位网格检查：所有可容纳最大敌人的格点均须连通到出生区，可通行比例至少为 72%。
- 每个种子最多尝试 8 个确定性候选，候选不合格会重试；全部失败则使用也经过校验的安全固定草场。生成不会把校验失败的布局交给渲染或战斗。
- 默认首次进入生成一个种子；返回菜单后再次出发换新种子。「重新开始」和失败重开保留当前地图。URL 中显式指定 `?seed=forest-42` 后，返回菜单重新出发也固定该种子。要恢复随机，打开不带 `seed` 的地址。
- 游戏下方显示种子，暂停菜单的「复现地图」链接包含完整种子。种子支持文字，去除首尾空格后取前 64 个 Unicode 字符；不会切断表情字符。生成规则当前为版本 1，地图数据、校验结果和重试序号可通过开发状态查看；改变生成规则时应升级版本。同一种子复现地图布局，不固定战斗中的其他随机事件。
- 换图复用已加载的素材与共享几何体，释放旧地面纹理和旧景物材质。只在切换地图时重建场景，不在战斗帧内随机生成。

本轮没有加入区域警戒、撤离或奖励事件。外围仍沿用原半径 33 的活动边界，手机真机性能仍待验证。

## 验证与预览

`npm run build` 验证 TypeScript 和生产构建。`tests/world-sample.spec.ts` 检查单兽开局、素材加载、出生空地、地图切换、加载失败回退、水面阻挡，以及桌面/844×390 横屏预览的绘制调用上限。`tests/navigation-model.spec.ts` 验证整条主路净宽、开放区域连通、3 类敌人 × 16 方位 × 2 个转向编号的 96 条追击、怪群中的坦克追击、240 次出生位置及 8 处自动出怪。浏览器测试使用本机 Chrome；尚未做手机真机性能验收。

`tests/world-generator.spec.ts` 批量检查 256 个种子的净空、区域差异及全图连通，并验证生成器拒绝堵出生点、堵路及封闭可通行孤岛的布局。`tests/random-world-ui.spec.ts` 验证种子链接同时复现地面像素和碰撞数据、重开保留地图、新局换图、连续换图的 GPU 资源上限，以及换图后移动和出生逻辑使用新地图。

版本 1 的 `audit-0` 至 `audit-255` 批次中，252 个种子生成随机布局，4 个种子在有界重试后启用安全固定回退；256 个返回布局全部通过校验，回退布局也可由同一种子复现。没有为了提高随机成功率放宽连通要求。
