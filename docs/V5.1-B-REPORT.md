# V5.1-B：三武器和五融合自由构筑

完成日期：2026-10-19。对应 GDD 第十三章阶段 B；本次停止在 B，未进入阶段 C。

## 体验方式

从主菜单选择任意一只幻兽进入融合模式。升级三选一可获得另外两种武器，再选择「命中分裂」「范围扩张」「连锁弹射」，即可组成五融合构筑。升级仍是随机选择，不保证每次出现目标卡。

## 本阶段实现

- 三种幻兽共用三槽构筑，各自保留原主武器。另外两种武器可通过升级获得，武器不会重复占槽；武器等级成长留待阶段 C。
- 主武器维持基础间隔，副武器一 / 二分别采用基础间隔 ×1.6 / ×1.9；初次发射分别错开 0.31 / 0.62 秒，攻速强化同时影响三个独立冷却。
- 五种融合按实际装备与通用改造解锁，投射物保留施法者身份与独立武器 ID。火种爆炸、水泡减速、叶刃穿透及融合动画可跨物种使用。
- 水泡的扩散和连锁同发协同，只执行一次范围结算，并共享直接 / 范围命中的去重记录；不会回头连锁已结算的目标。
- 叶刃可在首次命中时散射，同时由主弹继续连锁。派生只允许一代，子弹不会再次分裂或连锁。
- 按 GDD 收敛为两次额外连锁跳跃；同步更新旧的交替发射 / 三跳定向用例。
- 升级池排除自身主武器获取卡和无适用武器的专属改造；已获得或满级选项不再出现在候选中。连选队列在装备变化后立即按新构筑生成下一组选项。
- 保留 24 个投射物槽和 48 个特效槽。主武器先调度，两个副武器轮换调度顺序，副武器及多武器派生为主武器预留一轮空槽。派生上限为每模拟帧 6 枚、每模拟秒窗口 24 枚，满池时削减派生，保留已有攻击结算。
- 状态条显示三种武器名称、融合数量及协同提示，保留像素图标；读屏标签提供融合全名。火与水草图集同时可用，按攻击类型选择显示，无新操作按钮。
- 暂停、升级和死亡停止战斗推进；重开恢复所选幻兽的一种主武器并清除融合、慢速、弹体及特效。
