# V5.1-A：武器与幻兽身份解耦

完成日期：2026-10-19。范围对应 GDD 第十三章阶段 A；完成后停止，未进入阶段 B。

## 使用方式

从主菜单进入焰绒的「单兽技能融合原型」。击败敌人获得经验，升级三选一有机会出现「获得水泡弹」。选择后，焰绒保留火花弹，并独立自动发射水泡弹。水泡命中减速 30%，持续 1.5 秒；「命中分裂」仍可解锁爆裂火种。

## 已完成

- `RunBuild` 单独保存物种身份、装备武器、槽位、等级占位、冷却及发射统计。本阶段只开放焰绒的水泡副武器，不开放第三槽或武器升级。
- 主武器间隔 0.44 秒；副武器间隔 0.62 × 1.6 = 0.992 秒，首次释放延后 0.31 秒。攻速、伤害、射程和多重发射强化作用于两种武器。
- 投射物记录实际攻击 ID 与来源物种；颜色、形状和水泡减速按攻击 ID 决定，不把焰绒伪装成泡泡螈。
- 保留 24 槽投射物池，主武器先调度，副武器发射前预留一轮主武器的空槽；池满时延后攻击。
- 水泡获取卡只进入焰绒融合模式，购买一次后不再出现；历史模式不加入新卡。
- 使用既有升级卡与底部状态栏，显示武器名称及减速含义，无新增操作按钮，保留原像素素材。
- 升级、暂停、死亡停止战斗推进；重开恢复单主武器和空改造。

## 开发方法与回退

使用 mattpocock `codebase-design` 组织局内构筑模块；使用项目内 `ui-ux-pro-max` 与 `frontend-design` 保持像素游戏风格和清晰的文字状态提示。首次 UX 检索结果偏离主题，收窄检索后采用“不只依靠颜色表达状态”的建议。

开发前建立本地回退分支 `backup/v5.1-a-before-20261019`。保留已有 `.agents/` Skills，不提交、不推送，未删除现有代码或素材。
