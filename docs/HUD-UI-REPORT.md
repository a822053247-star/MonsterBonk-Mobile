# 第五阶段：HUD 统一

- 左上生命面板复用 `hud/creature-health-panel.png`，常规尺寸 230×78，小横屏 184×64。头像、名称、等级和实际生命数值由代码绘制；CSS 血条覆盖素材中自带的装饰血条，避免图片表现错误血量。
- 生命条使用绿色，低生命使用橙红色；经验条独立使用青蓝色，保留进度数值和无障碍 progressbar 属性。
- 统一森林深绿、淡金边框和字体。右上按钮保留至少 48×48 的触摸区域，摇杆和冲刺只调整颜色，不更改尺寸或事件处理。
- Boss / 精英保留真实血量、攻击提示、波次及金币信息；加粗血条，狂暴时变色。小横屏放到右上按钮下方，避免与头像和按钮重叠。
- 底部保留简短武器名称和现有融合图标，补充真实装备的水、草武器插画。素材失败回退原有 SVG 图标与 CSS 面板。
- 改动集中于 `src/ui.ts`、`src/style.css`，`src/game.ts` 仅增加 HUD 武器图标更新调用。未修改战斗、购买、技能数值、状态机或输入事件逻辑。
