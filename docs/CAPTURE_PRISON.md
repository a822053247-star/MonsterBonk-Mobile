# 战斗捕捉与幻兽囚坊

实现入口：`src/capture-spawns.ts` / `capture-rules.ts`（刷出资格与历史概率）、`src/enemy-capture.ts`（小游戏规则）、`src/capture-hud.ts` / `capture.css`（提示/封印环/光球）、`src/visuals/star-seal-capture.ts`（用户星印特效）、`src/capture-collection.ts`（永久收藏）、`src/prison-view.ts` / `prison-scene.ts` / `prison-scene.css`（囚坊）。`Game` 负责模式、输入、生命周期、音效和结算接入。

## 战斗操作与规则

- 闯关、无尽及捕捉测试启用；旧编队、犄角等模式不启用。六波、三武器、单摇杆、自动攻击及 Boss 胜利条件均沿用原规则。
- 主菜单「捕捉测试」当前仅生成沙甲团兽，场上最多1只；每4秒检查补充，沿用同一刷出资格概率、正常血量、削弱条件、无限封印符与24%小游戏基础成功率。普通「敌人测试」保留原名单。
- 18个物种分别累计刷出可捕捉个体的次数，概率为`max(0.1%, 2% × 0.5^次数)`，依次2%、1%、0.5%、0.25%、0.125%、0.1%，此后保持0.1%。成功刷出有资格个体即累计，不以击杀、捕获成功或失败计数；不同物种互不影响。当前没有账号系统，以当前浏览器/应用用户的本地存档为边界，独立保存在`monsterbonk:capture-spawns:v1`，重开、放回背包及放生均不重置；旧收藏数量不反推刷出历史，新规则从各物种2%开始。`Game`将`CaptureSpawns.roll`接到`Combat.captureSpawnRoll`；普通个体在成功分配对象池槽位后抽签，晶屑虫整组生成失败时不抽签、不计数。精英/Boss及不启用捕捉的旧模式不抽签。
- 正式闯关、无尽及捕捉测试中的普通敌人具有不可捕捉/可捕捉两种状态（`Enemy.captureState`）。出生时仅抽中资格的个体（`Enemy.captureCandidate`）在受到伤害降至实际最大生命40%时进入可捕捉状态；未抽中个体保持正常伤害与死亡流程；跨阈值的伤害（包括致命一击）将生命保留在40%，后续伤害无效，燃烧计时暂停，友军治疗不解除状态。精英/Boss与旧模式保持原伤害和死亡规则。出生保护结束、目标存活且无遮挡，距离15内按E（原2.5的6倍）或手机捕捉按钮启动；可捕捉状态不冻结移动，但接触、碰撞与冲撞均不再伤害角色；接触扫描排除目标，`scaledContactDamage`也直接返回0，远程攻击停止，进入该状态时按来源ID清除其已发射弹体；封印过程才锁定目标。`HostileShot.sourceEnemyId`由普通远程敌人发射时写入，Boss复用及清场时清理，避免污染共用弹池。头顶仅显示高对比金色“按E 捕捉”文字牌（复用72个DOM标记），近距离标记反色高亮；顶部封印符/捕获数/说明文字已移除，按钮显示目标名称。
- 封印符无限，不消耗次数、不受携宝兽掉落限制；`Game`不再追加捕捉机会，诊断字段使用`unlimitedSeals: true`。3秒冷却，不能并行捕捉；失败/超时/外部清场取消均不发死亡奖励。
- 收缩环历时1.6秒。58%–82%进度内为合格窗口，其中66%–74%为优秀窗口（优秀优先判定）；窗口外/超时为未命中。合格按物种基础率，优秀额外增加20个百分点、最多100%；例如沙甲团兽24%→44%。18种基础率互不相同、介于20%和60%，真值以`CAPTURE_RATES`为准。`sealGrade`/`sealChance`是规则与UI共用判定；优秀加成不保证捕捉成功。提前点击/错过窗口/超时为不合格，每个捕捉目标额外有5次重试（首次加5次，共最多6轮时机判定）。不合格先等待3秒，在封印圆圈中央以大字显示3、2、1重试倒计时（暂停冻结），保留目标、锁定和星印特效，随后自动重置收缩环并消耗1次重试；重试耗尽再不合格才最终失败并离场。合格/优秀后的概率失败不重试。最终成功或失败均在结果动画结束后消失，只有成功计入永久收藏。
- 目标设置`captureLocked`，空间索引不再选中目标。进入小游戏即暂停整个战斗：玩家移动/冲刺、敌人AI与移动、自动攻击、弹体、伤害、燃烧、技能冷却、波次/出怪及局内计时均冻结；只由`Game.stepCapture`推进收缩环、重试倒计时、捕捉结算和专用特效。捕捉结束/取消后自动恢复战斗，不累计补算冻结期间的战斗时间。
- 小游戏使用居中放大面板、青色合格宽环/金色优秀窄环、窗口文字提示及两档成功率；触摸按下即判定，支持按钮键盘激活。判定后保留1秒，分别显示时机档次和捕捉结果，附加扩散双光环、优秀强化金色粒子；所有运动由模拟时间驱动，暂停冻结，减少动态偏好停用装饰性运动。成功或失败均通过敌人实例scale收缩并移除目标；成功额外显示星印和光球飞入反馈并记录捕获；不进入死亡、经验、金币、爆孢爆炸、携宝奖励或遗物击杀链。精英和Boss始终排除，因此第六波必须击败Boss。
- 战斗和小游戏均用固定步长推进；捕捉期间小游戏独立按1倍速度计时，不受战斗倍速影响，战斗画面使用固定插值及冻结的动画时间。手动暂停/切后台/转竖屏仍会冻结小游戏，恢复后继续；选卡/宝箱/商店不会在捕捉中途插入。目标外部死亡/清场/对象ID变更取消；取消时只恢复同ID对象，避免污染新池槽。spawn、reset及clearWave清理个体捕捉资格、状态、保护与缩放；玩家刷出历史独立持久化，不随战斗清理。模式开关由`Game.start`同步到`Combat.captureEnabled`，离开战斗关闭。阈值共用`src/capture-rules.ts`，`Combat.isCaptureReady`统一状态判定，伤害入口负责跨阈值保命。
- 开始、成功、失败三种音效走GameAudio合成缓存、音效开关、声音数量上限和暂停生命周期；取消没有成功/失败音。结果音在封印判定发生时播放。
- 捕捉入口仅保留幻兽头顶标记，移除右侧重复的大按钮；当前最近且在捕捉距离及视线内的标记支持点击/触摸，电脑仍可按 E，冷却时禁用点击。其他目标的标记保留定位提示。
- 进入可捕捉状态后，幻兽视觉体积放大至130%，身体每2.4秒柔和闪亮一次，周围附三枚金色闪点；头顶标记、血条和捕捉收缩同步缩放。效果复用实例批次，由视觉时间驱动，暂停冻结；减少动态偏好改为静态高亮和闪点。仅改变外观，不调整碰撞、属性、捕捉距离或概率。
- 成功写入收藏后，顶部显示金色星印通知“已捕捉到幻兽囚坊”，附幻兽名称与劳作提示；存档失败时改为明确提醒勿关闭页面。通知不拦截操作，持续3.6秒并淡入淡出，固定步长计时、暂停冻结、重开清空，兼容手机横屏及减少动态偏好。

## 收藏与经营

每次成功即写入`monsterbonk:prison-collection:v1`（版本1，18种计数与最近2048个幂等收据）；结算战报列本局捕获。重开只清空捕捉冷却、小游戏和本局列表，永久收藏保留。存档异常保留内存并在反馈中提示，返回菜单/退出时重试写入。清除浏览器数据会清除本地记录，无云存档。

主菜单「幻兽囚坊」位于「无尽挑战」右侧，复用主玩法按钮尺寸与结构，使用黑色铁栏纹理及囚笼SVG图标；底部捕捉测试、敌人测试、旧版模式入口靠左排列。点击「幻兽囚坊」进入同应用Canvas场景；无iframe、无独立项目跳转。完整复用用户提供`C:/Users/Administrator/Desktop/del/幻兽囚坊/del/src/main.ts`中的绘制、工位运输、委托、可见升级、怪物性格互动、越狱及流光萤火逻辑，改造成可挂载/释放的模块。怪物图片直接读取本游戏`assets/pixel/enemies/`，不迁移原图集。

- 六间囚室，名册只列永久捕获种类；初始囚坊为空。移除原演示版免费抓怪及18种全解锁；原独立项目存档不导入。同一种幻兽可在战斗中重复捕获，每次成功增加收藏计数；囚坊按实际捕获数量允许同种多只入住，六间囚室总上限不变。名册显示已捕获/入住数量，不显示物种名字；已全部入住时选中现有个体。满员可替换选中/休息中的其他物种，替换的个体继续保留在收藏；读取存档时按捕获数量校验入住上限。`PrisonOptions.count`由`PrisonView`接入当前拥有数量（放生会减少数量）。
- 囚坊中所有物种统一按囚室内部尺寸的50%等比缩放（`CREATURE_CELL_RATIO`），可见主体最长边以半个囚室为基准；常驻、劳作、越狱与放生离场共用同一绘制。素材加载时缓存透明像素边界，剔除透明留白后保留身体比例、底部贴地；背包缩略图复用相同裁剪边界。阴影、选中圈及劳作道具随主体同步缩放，不更改战斗素材或战斗大小。
- 囚坊怪物移动速度上限与摆动频率降为原来的40%，行走起伏减小；活动萤火虫及背景萤火的飞行/摆动降为原来的35%，点击后改变飞行相位的幅度减小。模拟生产、事件时钟保持原步长；场景选中标签、名册、底部信息及提示不再显示物种名字，以囚室编号识别。四个资源图标统一横排、中心线、间距及数字对齐，修正箱子与草叶的局部绘制偏移。
- 点击幻兽弹出操作面板，可选择“放回背包”或“放生”，也可直接点击工位继续派工。放回背包只移除囚室居民、保留拥有数量；放生通过`PrisonOptions.release`调用`CaptureCollection.release`，成功写入收藏存档后减去一只并移除居民。两种操作均停止劳作、归还正在搬运的矿石并清理相关互动/越狱状态。放生的幻兽以独立视觉对象慢速走向出口，出口抬闸放行，到达后0.85秒淡出；期间不参与生产或交互，空囚室可立即复用且不污染离场动画。动画暂停冻结，离开囚坊即结束视觉，已保存的放生/回包结果保留。保存放生数量失败时保留原幻兽并提示重试。
- 任何怪物均能选择挖矿/搬运/种植，保留原劳作动画与运输链；点击怪物后点工位，或数字1–6选择、Q/W/E派工、R休息、Enter收货。
- 顶部重复名册入口合并为一个背包图标；点击背包/按M打开“怪物背包”，列出全部已捕获种类与数量（无物种名字），点击自动放入空囚笼；满员沿用替换规则，已全部入住的种类选中现有个体；空背包提示先去战斗捕捉。点击仓库领取、委托板/按B交付、建筑标记先预览费用再点升级。互动气泡、出口落闸、追逐萤火及生产障碍仍使用原场景交互。
- 囚坊存档隔离在`monsterbonk:prison-scene:v1`（保留原源项目内部version7结构及校验），保存居民、工种、产物、委托、建筑和事件；读取时剔除不在收藏中的居民。经营资源不反向增加战斗属性。
- 关闭囚坊保存并取消RAF及全局监听器，重新进入恢复；隐藏页面不追补离线产量。Canvas与名册样式隔离在ShadowRoot，支持横竖屏；主游戏竖屏战斗限制保持。
