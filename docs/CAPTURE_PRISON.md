# 战斗捕捉与幻兽囚坊

实现入口：`src/enemy-capture.ts`（规则）、`src/capture-hud.ts` / `capture.css`（提示/封印环/光球）、`src/visuals/star-seal-capture.ts`（用户星印特效）、`src/capture-collection.ts`（永久收藏）、`src/prison-view.ts` / `prison-scene.ts` / `prison-scene.css`（囚坊）。`Game` 负责模式、输入、生命周期、音效和结算接入。

## 战斗操作与规则

- 闯关、无尽及捕捉测试启用；旧编队、犄角等模式不启用。六波、三武器、单摇杆、自动攻击及 Boss 胜利条件均沿用原规则。
- 普通敌人生命不高于实际最大生命40%、已结束出生保护、无rank、存活且无遮挡时可捕捉。头顶显示淡金封印标记（复用72个DOM标记）；距离2.5内按E，手机可点同一捕捉按钮。
- 每局1张基础封印符；实际击败携宝兽获得宝箱掉落时追加1张，最多追加2张，整局总上限3。消费发生在成功启动时；失败/超时/外部清场取消不会发死亡奖励或返还封印符。3秒冷却，不能并行捕捉。
- 收缩环历时1.6秒；点击时间在58%–82%范围内时，按物种固定概率判定；18种基础率互不相同、介于20%和60%，真值以`CAPTURE_RATES`为准。错过/提前点击/超时失败，没有额外永久惩罚，敌人原血量与战斗状态保留。
- 仅目标设置`captureLocked`；敌人AI、移动、接触攻击、普通弹命中及damageEnemy排除目标，燃烧计时暂停；空间索引不再选中目标。已在场的敌方弹体继续飞行，其他战斗和玩家行动继续。
- 成功时通过敌人实例scale收缩、星印和光球飞入反馈，然后只移除目标并记录捕获；不进入死亡、经验、金币、爆孢爆炸、携宝奖励或遗物击杀链。精英和Boss始终排除，因此第六波必须击败Boss。
- 模拟固定步长推进；暂停/选卡/宝箱/商店不推进小游戏。目标外部死亡/清场/对象ID变更取消；取消时只恢复同ID对象，避免污染新池槽。spawn及clearWave清理保护/缩放状态。
- 开始、成功、失败三种音效走GameAudio合成缓存、音效开关、声音数量上限和暂停生命周期；取消没有成功/失败音。结果音在封印判定发生时播放。

## 收藏与经营

每次成功即写入`monsterbonk:prison-collection:v1`（版本1，18种计数与最近2048个幂等收据）；结算战报列本局捕获。重开只清空临时机会、小游戏和本局列表，永久收藏保留。存档异常保留内存并在反馈中提示，返回菜单/退出时重试写入。清除浏览器数据会清除本地记录，无云存档。

主菜单「幻兽囚坊」进入同应用Canvas场景；无iframe、无独立项目跳转。完整复用用户提供`C:/Users/Administrator/Desktop/del/幻兽囚坊/del/src/main.ts`中的绘制、工位运输、委托、可见升级、怪物性格互动、越狱及流光萤火逻辑，改造成可挂载/释放的模块。怪物图片直接读取本游戏`assets/pixel/enemies/`，不迁移原图集。

- 六间囚室，名册只列永久捕获种类；初始囚坊为空。移除原演示版免费抓怪及18种全解锁；原独立项目存档不导入。拥有同一种的多次捕获会增加收藏计数，但囚坊同种仅保留一名代表；满员可替换选中/休息中的代表，旧种类保留在收藏。
- 任何怪物均能选择挖矿/搬运/种植，保留原劳作动画与运输链；点击怪物后点工位，或数字1–6选择、Q/W/E派工、R休息、Enter收货。
- 点击名册/按M入住；点击仓库领取、委托板/按B交付、建筑标记先预览费用再点升级。互动气泡、出口落闸、追逐萤火及生产障碍仍使用原场景交互。
- 囚坊存档隔离在`monsterbonk:prison-scene:v1`（保留原源项目内部version7结构及校验），保存居民、工种、产物、委托、建筑和事件；读取时剔除不在收藏中的居民。经营资源不反向增加战斗属性。
- 关闭囚坊保存并取消RAF及全局监听器，重新进入恢复；隐藏页面不追补离线产量。Canvas与名册样式隔离在ShadowRoot，支持横竖屏；主游戏竖屏战斗限制保持。
