## 工程实现

- 新增 `src/enemy-pixel-view.ts`：每种贴图一个固定容量 `InstancedMesh`，使用脚底为原点、朝向相机的平面。共两种贴图、两个批次；每批预留 48 个实例槽，全体实际敌人仍受原 48 个实体池限制。
- 扩展 `PixelTextureCache` 的素材映射，复用现有透明裁剪、NearestFilter、sRGB、关闭 mipmaps 和边缘 ClampToEdge。三兽素材加载与显示方式保持原样。
- 修改 `CombatView`：贴图就绪后，只隐藏对应敌人的旧身体、眼睛和角；保留坦克身体与护甲。出生预警、脚影、血条、锁定圈、扑击预警、恢复圈和原死亡粒子仍复用既有批次。像素敌人的血条随贴图头部位置调整。
- 实例矩阵保留主体比例与统一脚底锚点；短横屏的普通怪约 34–39 CSS 像素高，快速怪约 29–33 像素高。只改变显示尺度，不修改碰撞。
- 贴图采用 alpha cutout，透明角落不写深度；不强制置顶。受击闪白通过一个逐实例属性实现，避免整批一起闪，也不在每次受击时创建材质。
- `Game` 仅负责开关、传递相机与视口、诊断和释放。原逻辑模块未改动，所有自动攻击仍走现有伤害结算。

第一次进入编队原型才创建两类敌人贴图资源，生成、死亡、暂停或重开不重新创建批次。重开清空实例数量并复用纹理；销毁释放实例缓冲、几何、材质和纹理租约。加载尚未结束时销毁，异步完成后不会重新挂载。
