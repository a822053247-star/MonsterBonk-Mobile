# 怪潮多样化、疾芽专属行为与第五波商店过渡

## 玩法目标

- **不再只有一种怪物**：正式六波的普通半批怪潮采用约 3 份赤团、1 份疾芽、1 份岩甲的生成候选，受当波阶段的疾芽/岩甲同时存活上限约束。配额满了回退赤团，因此实际同屏比例取决于击杀速度、存活配额和安全出生点；晶屑虫、爆孢怪、携宝兽仍由现有难度导演独立安排。保留各波 60/90/120/160/200/120 的总上限。
- **疾芽专属动作**：正式六波模式的疾芽在已准备突进的追逐阶段会向左右交替包抄；旧有明确预警、瞄准锁定、冲刺和固定攻击恢复仍然保留；扑空后轻微后撤，给玩家反击窗口。此前旧模式的疾芽规则不变。
- **岩甲更难清掉**：基础 HP 100→125；正式六波仍按照现有波次生命倍率变化。第四波精英固定480HP、第六波 Boss 固定6000HP，不继承普通岩甲生命。
- **前四波连续过渡**：第一至第四波结束先统一收回场上经验、结算奖励、清除旧敌人/技能和危险预警，进入3.5秒原地休整。游戏画面仍保留战场并明确显示下一波倒计时，玩家在此期间无法移动或受伤；倒计时结束自动进入下一波，不开放商店。
- **只有第五波结束才有商店**：第五波同样先经过3.5秒可见倒计时，提示准备最终 Boss，再显示现有商店。购物与刷新逻辑、四种商品、金币价格保持不变。购物完进入第六波。第六波胜利/失败直接结算。
- **携宝兽免费刷新权益不丢**：前五波任意一次成功抓到携宝兽，就为第五波结束后的商店累计最多一次免费刷新；没有抓到的玩家依然能用累计金币购买/付费刷新。爆孢连锁奖励仍按每波最多9金币结算。

## 状态机

```text
第1波 → 休整3.5s → 第2波 → 休整3.5s → 第3波
  → 休整3.5s → 第4波 → 休整3.5s → 第5波
  → 休整3.5s（提示商店） → 商店 → 第6波 → 胜/败
```

`RunFlow.phase` 新增 `intermission`；`RunFlow.updateRest(dt, combat)` 负责自动切换。升级弹窗若仍未选完先完成已有升级决策，再进入休整，不在休整期间模拟战斗。累计休整时间计入 `totalElapsed`，战斗总时长仍是455秒。每次重开清除休整和商店状态。

## 保留已有素材

使用既有赤团、疾芽、岩甲像素方向图；疾芽的绕侧与后撤使用现有的走路/冲刺动画，不新添贴图。波间提示复用 `#welcome` 标题、文本及渐隐效果；商店保留已有界面与四类商品素材，无需新的过场动画或音频。

## 实际验收

- 新混编在普通敌人与危险单位实时配额之间保持数量上限；疾芽有可观察的侧移、蓄力冲刺和短暂撤退。
- 岩甲 HP 增长只作用于普通敌人，精英/Boss 仍保持独立生命值。
- 前四波没有商店，休整保留角色生命、升级、金币并清除旧战斗危险；第五波结束休整后唯一一次可购买与刷新，真正进入第六波。
- 手机宽度、Chromium/WebKit 过渡/商店 UI、原有特殊敌人奖励、波次模拟、旧模式继续自动测试。

注意：新的生成比例为**尝试生成的权重**，不是强制每一帧活跃怪比例相等。移动端帧率、实际难度曲线仍需真机长时间试玩。
