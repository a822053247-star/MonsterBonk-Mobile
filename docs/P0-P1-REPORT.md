# V4.0 P0 / P1 验收记录

日期：2026-10-18。范围仅工程审查、安全检查点、设计文档与三兽编队技术原型。

## 交付与使用

启动方式不变：`npm run dev` 或原启动脚本。主菜单点击「三兽编队原型」。焰绒沿用现有模型与淡色脚环，泡泡螈为蓝色占位体、芽刺兽为绿色占位体；只有摇杆操作，全员独立自动索敌与发射，主控承伤和拾取，共享生命。也可用 WASD / 方向键验证移动。Space / Shift / J 在原型中不触发动作。

为验证两位伙伴，本原型预置三只；正式单兽开局与 Lv.2/Lv.4 槽位解锁仍属于 P3。伙伴采用小阵型、局部避障、滑动和有效落点恢复，偶发卡住或落后时允许安全重定位，尚无导航网格。三种攻击目前只区分颜色、形状、基础伤害和冷却；范围/减速/穿透的完整机制留给后续阶段。

## 复用与修改

复用 `Game` 固定步长循环、原 Player 移动/碰撞、正交相机、`Input` 触摸、`Combat` 敌人/投射物/经验/效果池、扫掠碰撞、`damageEnemy`、`Progression` 与原强化 UI、音频、动态画质、后台暂停、死亡和重开。继承的旧被动法术仍围绕主控结算。

新增 `src/party.ts`（CreatureDefinition/Instance、PartySystem、缓存的统一基础属性入口、伙伴跟随）和 `src/party-view.ts`（廉价占位显示与释放）。编队容量默认为 3，构造参数预留 4；允许同种重复。新增两个测试文件、生产冒烟脚本、GDD、迁移计划与本记录。

局部修改 `game.ts`、`combat.ts`、`combat-view.ts`、`input.ts` 接入可选编队上下文、独立发射与仅移动输入；`ui.ts`、`style.css`、`index.html` 增加名称、原型入口和编队提示，更新 README。保留三个旧模式回归入口及其原操作。

地图、经验数值、相机、旧模型/Sprite 加载、器官资源和已有挑战逻辑未改动。16 个受保护文件经过 Git 内容哈希比对，与本轮前快照一致；所有旧素材保留。

## 尚未验证与阶段边界

- 未在 Android/iPhone 实机测试，未证明 30/60FPS、长期内存稳定性或高密度敌潮性能；浏览器为桌面模拟，生产截图采用 Chromium 软件 WebGL。
- 没有正式六波通关、Boss 或最终平衡验收。现有最多 48 敌人的全量避让仍是旧实现，扩大密度前须优化；原型保留池容量，满池时自动攻击延后重试。
- 本轮不做 P2 像素显示接口，也未做等级解锁、金币/商店、羁绊克制、完整物种机制、新进化、随机区域/警戒/撤离、闪光蛋、祭坛或完全体材料。没有生成新美术图。
