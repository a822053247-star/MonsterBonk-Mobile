# 无尽通用遗物与休整服务

六件遗物由 `src/content/relics/endless-passives.ts` 定义，注册到现有遗物工厂，所有幻兽通用。通过 `endlessOnly` 只加入无尽升级、商店与合法宝箱候选；每件本局最多获得一次，闯关与历史模式不加入新候选。由闯关续接无尽后按当前模式开放。保留单摇杆、自动攻击和三武器限制。

| 内容 | 效果 | 取舍或限制 |
|---|---|---|
| 专注重炮 | 所有武器伤害×1.30 | 武器攻击间隔×1.20；不改变独立自动范围技能 |
| 疾行契约 | 移速×1.15 | 最大生命×0.85；当前生命仅压至新上限，不触发受伤 |
| 远距透镜 | 武器射程最多×1.20，显示封顶后的逐武器前后值 | 攻击间隔最多×1.08，按实际射程增长比例折算；封顶武器不受代价，全部封顶时不再出现 |
| 重型弹药 | 主投射武器单发伤害×1.50 | 每轮少1枚额外主弹，至少1发；需实际主投射武器和分枝魔法≥2级，不修改潮刃伤害或派生数量规则 |
| 残血决意 | 当前生命≤最大生命35%时，武器直击×1.30 | 普通主攻击命中时判断；持续、复制、派生和自动范围技能不重复加成 |
| 精英猎手 | 对精英/Boss的武器直击×1.25 | 对普通敌人直击×0.90；派生/持续伤害不重复加成 |
| 休整补给 | 立即恢复35生命，不超过上限 | 现有商店治疗的无尽扩展，每次商店限购1次，刷新不重置；满血禁买 |
| 契约强化 | 获得1级魔力浓缩，遵循原5级上限 | 最大生命×0.95，仅压低当前生命上限；每店1次、本局最多3次，刷新不重置；魔力满级或待选升级时不可购买 |

无尽商店保留三个原奖励位，固定显示补给与契约两个服务位。补给沿用原治疗价格曲线；契约取普通商品无尽价格的60%，再按已签次数增加10%/次、向上取整到5金币（相对普通价格为60%/66%/72%）。首店普通强化105金币时，首签65金币。购买仍经过商店token、余额、合法性和存活检查，成功后才扣款和累计消费；正式闯关商店布局与补给规则保留。

## 接入

- `Progression.skills` 按 `endlessOnly` 筛选；`calculateStats` 在正式构筑计算疾行契约与主弹数量，升级/购买重算，无逐帧新循环。
- `applyRelicDefinition` 在现有攻击快照中应用伤害、间隔、射程、范围倍率。融合继续复用同一规则与能力标签，不建立额外攻击管线。
- `Combat.damageEnemy` 只在主武器直击时读取残血与精英条件，保留原始伤害谱系，避免派生重复放大。飞叶分裂子弹明确标记为派生，其他派生预算不变。
- `Combat.vitalContracts` 保存本局契约次数，最大生命取原结果再乘 `0.95^次数`；跨波/商店保留，整局reset清零。契约通过现有 `grantUpgrade('damage')` 授予强化，治疗通过原生命结算。
- 六件遗物的 `art.png` 绑定用户提供的透明PNG，供升级、商店、构筑与宝箱展示共用；两个服务位通过 `ShopItem.illustration` 绑定补给/契约图标。仍使用原卡框、文字与购买按钮，缺图沿用既有回退。

没有新增弹体、粒子、材质、持续范围检测或常驻更新循环。静态倍率作用于已有攻击快照，条件增伤作用于命中事件。

验证：TypeScript `tsc --noEmit` 与差异空白检查。按用户要求未运行测试，也未做生产构建或实战平衡验证。

## 对照 BALANCE_DESIGN_V1 的静态修正

以第3.1节额外主弹75%快照、第3.2节最终射程封顶与实际收益提示、第9.3节有限经济/治疗和第14.3节遗物收益复查门槛为约束；不将文档其他提案自动纳入开发。

- 重型弹药不再把额外主弹减半取整。分枝2级时原3发的伤害权重为2.5，调整为2发×1.50，权重2.625，理论整轮直击+5%；分枝3级原4发权重3.25，调整为3发×1.50，权重3.75，理论+15.38%。分枝1级不出现此遗物。以上假设每枚弹完整命中、忽略过量伤害、连发调度及弹池阻塞，不等于实战收益；以更少覆盖换取更集中伤害，派生继续读取调整后的攻击快照。
- 远距透镜取消半径惩罚，改为有上限的间隔代价。对每把武器计算 `g=clamp((最终射程后/最终射程前-1)/0.20,0,1)`，间隔乘 `1+0.08*g`；没有射程收益就没有间隔代价。所有已装备武器均无收益时排除候选；获得后继续升级到封顶，代价随实际收益降低至0。升级卡和商店显示当前逐武器的真实射程前后值，其他购买改变射程后同步更新未购买商品。范围半径不再缩小。
- `RunBuild.weaponRange` 共用现有投射/刃/雷/横扫公式和上限，供透镜收益与代价计算；投射、刃、雷的实际施放直接复用，横扫仍由同一 `flameSweepStats` 计算。预览不提高任何最终上限。
- 契约每次生命代价降为5%，三签后保留原上限85.7375%，而非原72.9%；金币同步降价。它授予原有魔力浓缩等级，不突破5级或本局3次上限，不增加免费治疗。与疾行契约、血契同时持有时仍按乘算承担生存取舍，组合强度未作实战验证。

修正后完成TypeScript类型检查与差异检查；未运行测试、战斗模拟或生产构建。静态预算已修正明确的负收益问题，不能据此宣称V1的整局/Boss时长、有效伤害或胜率目标已达标。
