# P0 步骤 3：特殊敌人 = 成长选择与风险奖励

本变更以六波难度导演（PR #3）的 `main` 为基线，**不增加新贴图、不修改攻击伤害、怪物血量、掉落原值或六波刷怪调度**。使用现有的携宝兽追踪/金币图标、爆孢预警与爆炸、森林商店刷新符文。

## 玩法

1. **携宝兽：抓到才有一次免费商店刷新**
   - 保留真实击杀原有奖励：12 金币 + 8 经验（经验仍需拾取，或在波次结算时回收）。
   - 此外授予“本波结束后的商店免费刷新 ×1”，`RunShop` 由 `RunFlow` 在正式波次结算时传入；同波重复获取至多一张，不跨波、不跨重开累积。
   - 免费刷新不增加**付费**刷新的价格：用完后仍是 5、10、15……金币；修订令牌照常变化，旧点击/双击不会多次扣费或重复领奖。
   - 未追上、逃走、无可刷新商品，均不生成无条件强力奖励；免费刷新不保证稀有卡、也不会自动购买。
2. **爆孢怪：连续引爆形成有限的商店金币奖励**
   - 真实孢子爆炸杀死另一只爆孢怪（已有的 `sporeChainKills` 计数）时，每次额外获得 3 金币，每波最多奖励 9 金币。
   - **仅在波次结算**发放，等待升级选择完成以后再发；同一个波次的结算重复调用也不会重发。
   - 既有爆孢死亡造成的普通经验与金币仍按原规则发放；不取消孢子对玩家12点伤害的危险。
3. **所有构筑：商店第二格改为当前武器的适配升级**
   - 焰绒优先「命中分裂」、泡泡螈优先「范围扩张」、芽刺兽优先「连锁弹射」；满足/获得后逐步退回当前武器强化、攻速/伤害及其他可用升级。
   - 只会从 `Progression.canGrant` 的合法候选里挑选，不突破武器槽上限、不强制刷新稀有遗物、不减商品价格。
   - 第一格新武器、第三格稀有候选、第四格补血/生命升级继续沿用已有逻辑，**没追到携宝兽也有合理的商店升级路线**。

## 数据流程

`Combat.damageEnemy` 对真实携宝兽击杀增加累积计数 `treasureCaught`（仅正式 `usesRunBuild` 模式），不另造死亡判定。
`RunFlow.resolveBoundary` 计算与上次已结算时的差值，处理孢子连锁上限和携宝兽商店权益；如仍有等级选择，则先处理等级，不预发补贴。
`RunShop` 的刷新令牌依旧避免陈旧操作；免费次数独立于付费刷新次数，最多一张。
`ui.ts` / `game.ts` 利用现有商店状态文字、金币图标及刷新符文展示权益，不加载新美术。
