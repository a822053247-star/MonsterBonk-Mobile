# 暂停与战报界面可读性

2026-10-21，分支 `codex/readable-run-panels`。仅调整界面展示、文字组织和相关验收，不修改战斗平衡或胜败判定。

## 设计与实现

- 沿用森林绿 `#173e33`、浅叶绿 `#deedac`、暖纸色 `#f7edcf`、深绿文字 `#294c3e`、暗金 `#bfa36b`。中文优先使用本机微软雅黑/苹方，不增加网络字体或美术依赖。
- 暂停页左侧保留继续、设置、重开、返回菜单和地图重放入口，右侧为独立滚动的装备与构筑。标题、装备名、正文形成明确层级；长遗物说明分开显示名称、收益和代价。
- 战报在顶部横排展示时间、击杀、经验与波次/金币，下方三把武器并排展示，再按强化、融合、稀有道具和进化分组，消除原来的长串斜杠与大面积空列。
- 正文16px，武器名18px（短横屏17px）、分组标题17px。视口尺度 `clamp(1px,min(.075vw,.12vh),2px)` 使1920宽桌面正文约21px、4K正文32px。短屏操作说明14px，武器角色标签13px；不会把核心正文缩回9px。
- 复用武器升级插画，五格刻度表示武器等级；小宽度隐藏装饰刻度但保留文字等级。图片失败时仍可读文字与SVG。
- 保留羊皮纸九宫格边框；正文与边框安全区独立。长内容可滚动，主要动作不随详情一起滚出视口。胜利单次入场及减少动态效果偏好仍有效。

## 验证

`tests/run-panels.spec.ts` 覆盖3840×1907、1920×1080、1280×720、844×390、568×320（左右44px/底部21px安全区）；检查大屏字号、无横向溢出、长详情末尾可达、动作保持可见、键盘恢复/重开、暂停不推进战斗、初始构筑与缺图降级。相关回归见 `artifacts/run-panels-regression.log`。

Chromium/WebKit共55项通过；1项仅适用于Chromium CDP的多指注入测试在WebKit按既有声明跳过。`npm run build` 与 `git diff --check` 通过，构建保留既有Three.js大块体积提示。修改期间主分支合入了地图更新，本UI分支已保留其最新基线 `73b35cf`，未回退地图实现。

原战报测试改为检查滚动后能看到完整构筑，不再要求极短横屏中把全部内容缩小塞进首屏。旧构筑UI测试的强制选卡夹具重置抽卡保底计数，避免已有保底机制替换其指定稀有卡；另校正原有 `Lv.2` 为当前真实文案 `2级`。三武器测试改为检查现有HUD标题中的融合及暂停页的完整构筑，移除对已经不再使用的通用“融合协同”提示语的断言。生产抽卡、经验、卡池和HUD规则均未调整。
