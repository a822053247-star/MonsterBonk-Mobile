日期：2026-10-24。状态：**第1–7节保留原设计；第8节记录已接入的代码与素材，游戏运行尚未验证**。

## 1. 核心体验

**沿宽阔的冷却玄武岩台地前进，绕过熔岩池和黑曜岩岛，在灰烬空地回转、聚怪并返回拾取。**

建议地区ID：`volcano`。与草甸的分散树丛、遗迹的古道残坛、雪原的浅色冰原区分，火山以低明度的大块冷却岩面、断续灰烬带、少量高亮熔岩地标构成。地形有方向感，但允许四向自由绕行，不是单条岩浆桥或封闭火山口。

拟用选路文案：

- 名称：熔岩火山
- 地形短句：玄岩台地 · 熔流岩岛
- 描述：沿灰烬空地绕过熔池与黑曜晶岩，在宽阔台地回转迎战。
- 奖励说明：封印宝箱优先武器获得或强化；数量不变。

首版奖励偏好拟沿用已有 `weapon`，无额外火系掉落、元素克制、敌人倍率或奖励保底。名称中的“火山”不自动引入喷发伤害、热量条、周期落石或新Boss。

### 2.3 完整分割与无损导出规则

实施时按以下顺序制作素材，禁止重新生成一张外观近似的图集替代原素材：

1. 先固定22件的语义身份，以编号核对图中的主体作为种子，不按全图等宽/等高切块。
2. 为主体外的半透明红边、火苗、熔滴和小石子分配唯一归属。候选归属应受空间距离、同一火焰/岩石轮廓约束；连通性只能辅助判断，不能把相连柔边自动合并。
3. 特别复核：01与02之间、03–05之间的红边；07／08与13火苗之间；11／12与17火焰之间；16与21／22之间。它们的视觉排布紧密，矩形外扩可能串入邻件。
4. **13号火焰石座的火苗从y≈580延伸，进入上一行高度范围。** 不能用“第三行从y=600开始”裁切；17号小火山的上方火苗也不能按第四行统一顶边切掉。
5. 归属确定后，保留属于该件的原始RGBA像素，包括alpha为1–127的柔边，不对RGB阈值抠图；相邻件像素在该件遮罩中清零。
6. 对每件归属像素求完整边界，再在四周加4像素透明边距。元数据中的 `reviewWindow` 只是主体框外扩4px的核对窗，**不是完整光晕边界，也不能直接作为最终导出框**。
7. 单件导出保留原分辨率和比例。文件命名拟为 `volcano-01.png` 至 `volcano-22.png`；导出偏移、源坐标锚点、裁后锚点、完整边界必须一起记录。
8. 如重新打包运行时图集，使用变尺寸矩形、至少4px隔离与透明边距，记录真实UV；不缩放成同尺寸格，不为贴格子裁掉火焰。以原图像素做还原对照，而不只看缩略图。
9. 双残柱、尖峰和枯木的视觉空隙要单独审视。碰撞半径不能由火焰高度或矩形外接框直接推导；12号双残柱若使用两个圆形足迹，显示、导航和落点迁移必须共用同一组足迹。

建议导出验收：22件数量与编号一致；主体无截断；无邻件碎片；火苗、熔滴与脚底石块完整；透明背景保留；锚点无统一居中导致的浮空；映射回原图后，归属范围内像素与源RGBA一致。以上是后续验收标准，本次未声称已经执行最终导出。

## 3. 空间与生成设计

继续使用当前 **64×64单位分块、32×32宏单元**。先保证通行骨架，再放障碍，最后补地面纹理。全图是无限冷却台地；亮熔岩池是独立实体障碍，不能穿过，首版不造成接触灼伤。普通地面的暗红裂纹为冷却痕迹，可正常行走。

| 单元 | 建议规格 | 目的 |
|---|---|---|
| 灰烬开敞面 | 每宏单元中心保留半径8的无障碍区域 | 阅读预警、转身与拾取，不是无敌区 |
| 四向通行骨架 | 中心连接四边中点，主通路净宽至少8 | 跨宏单元与分块保持连通 |
| 熔流岩岛 | 每宏单元最多1组、每组最多4件候选，放在通路之间角部 | 形成左右绕行，空间不足直接省略 |
| 高亮地标 | 每宏单元最多1件，候选中心间距建议至少20 | 熔池/火焰/亮晶不同时抢占画面 |
| 次级绕行口 | 不同岩岛间净宽至少6 | 不把玩家逼进单出口狭缝 |
| 原点安全区 | 至少半径8，无高物件或熔池占地 | 沿用现有出生安全意图 |
| 组内边界 | 不围成U形或闭合火山口；两端始终开放 | 避免贴障碍后无路可退 |

每块最多16件障碍候选，仅为上限，不要求填满。高亮候选建议为01、04、10、13、17、18；其他岩石和黑曜材质也有发光裂缝，需结合实景确认亮度，不能仅按“高亮名单”便断言画面足够安静。

组内小缝如果不足以通过玩家，不应画出明显通路的视觉承诺；优先拆散或省略物件，不用看不见的大圆把多个分离主体粗暴封起来。玩家足迹半径当前为0.62；大体型精英/Boss仍须按实际足迹验证，不能只验证玩家可走。

### 平面关系示意

```text
                  通往下一片灰烬空地
                          ↑
     黑曜岩岛        宽玄岩通路        熔池岩岛
       ↖                  │                 ↗
左侧连接 ←──── 中心开敞面（半径8） ────→ 右侧连接
       ↙             可聚怪、回转           ↘
     兽骨岩堆        宽玄岩通路        普通熔缝岩
                          ↓
                  通往相邻冷却台地
```

示意表达可走空间与角部障碍关系，不要求四个角全摆物件；一个宏单元只选一个角部岩岛，以减少满屏障碍与高亮重复。相邻宏单元的岩岛需检查距离和共同通路。

### 可复现与跨区约束

- 候选、变体、缩放、朝向与省略由种子和绝对宏坐标决定。改变布局朝向，不旋转原图造成透视失真。
- 跨单元距离筛选读取相同的周围候选并使用固定优先级，不能依赖哪个分块先加载。
- 通路、开敞面、事件占地、出生留白优先于所有地标。任何一项不满足时省略候选，不无限重抽。
- 地面纹理使用世界坐标采样；障碍由单一块拥有，完整可见底座与碰撞不得跨到未加载块后才补全。
- 切区可能发生在任意坐标，复用当前迁移对玩家、敌人和经验球的重叠修正；不能只保护原点。未解决的重叠沿用当前暂停保护。
- 继续使用已有缓存、Worker与主线程切片回退、版本取消、逐帧安装和 `World.revision`，不通过扩大活动区块数或敌人池解决布局问题。

## 4. 美术与战斗可读性

视觉目标是**暗而能辨路的岩面，承托少量高饱和熔流主体**，而不是把整张地图染成橙红。

| 层级 | 建议配色/处理 | 限制 |
|---|---|---|
| 主玄武岩 | `#45434A`，低频大块明度变化 | 不用纯黑吞掉黑曜岩描边 |
| 冷却岩面 | `#5B5556`，短而稀疏的裂纹 | 不铺满等大小方砖 |
| 灰烬带/开敞面 | `#76695E`，不规则柔和边缘 | 用明度引导通路，不画成窄桥 |
| 冷却裂缝 | `#7B4635`，低亮度、无闪烁 | 可行走，不模拟敌人预警 |
| 熔流/晶体 | 保留用户素材原色，适量分布 | 不新增整屏泛光或放大外围光晕 |
| 骨骸/黑曜刺 | 稀疏辨识地标，与普通岩石混排 | 不是奖励、可破坏物或交互入口 |

地面主体以冷灰、灰褐为主，留出红色冲锋、地震和火系武器的辨识空间。优先用低对比纹理与地标密度调整，首版不改变全游戏预警配色。火焰石座与小火山使用用户静态图；不凭单帧素材承诺喷发或火苗动画。

高物件沿用现有22%遮挡淡化，半透明火苗也随主体淡化，碰撞不变。低画质可减少未来可选的余烬装饰，但不能改变障碍数量、碰撞、地标主体或命中结果。首版不依赖天气粒子、实时灯光、折射或热扭曲。
