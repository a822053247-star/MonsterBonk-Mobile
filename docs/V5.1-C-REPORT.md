# V5.1-C：构筑深度验证

完成日期：2026-10-19。对应 GDD 第十三章阶段 C；未进入阶段 D，未加入六波、金币或商店。

## 体验入口

选择任意幻兽进入融合模式。升级时，已有武器的获取卡会变成武器强化卡；武器最高 5 级。稀有道具与互斥进化暂时通过升级三选一获得，后续商店可以复用现有构筑规则。

每级武器增加 20% 基础伤害；火花每级增加 6% 爆炸半径，水泡每级增加 0.1 秒减速时长，叶刃达到 3 级后额外增加一次穿透。进化仍需先拥有火花弹与「命中分裂」。

## 六件稀有道具

| 道具 | 实际效果 | 代价 / 限制 |
|---|---|---|
| 过载核心 | 爆炸及水系范围半径 ×1.5 | 所有武器攻击间隔 ×1.2 |
| 追猎之眼 | 一代派生弹以有限转向速度追踪附近可见敌人 | 派生弹伤害 ×0.8 |
| 破碎晶核 | 火种 / 荆棘每次分裂数量 +1 | 派生弹伤害 ×0.75，保留原弹体预算 |
| 潮汐遗珠 | 水泡减速时长 ×1.6 | 所有武器直接命中伤害 ×0.85，不削减范围伤害 |
| 专精徽记 | 仅装备一种武器时伤害 ×1.6 | 装备副武器后失效；暂停详情明确标注 |
| 回声符石 | 连锁距离 ×1.4 | 每次额外跳跃伤害额外乘以 0.7，逐跳衰减 |

同一道具本局只能获得一次。道具效果可叠加，但不会增加分裂代数、连锁上限或对象池容量。

## 两条互斥进化

- **狂暴火种**：火种爆炸半径 ×1.35，火花弹攻击间隔 ×1.25。
- **追猎火种**：派生火种追踪敌人，火种爆炸半径 ×0.75。

二者本局只能选择一条，选择后另一条从候选中移除，不允许切换。重开时清空路线。

## 形成的三种玩法方向

1. **单武器专精爆发**：把升级投入火花弹，配合专精徽记、过载核心与狂暴路线，换取更大覆盖范围；副武器会让专精加成失效。
2. **水火控制爆炸**：通过水泡与潮汐遗珠延长控制，火种处理聚集目标；需要用攻击间隔或直接伤害换取控制与范围。
3. **草系分裂连锁**：叶刃、分裂与连锁协同，配合破碎晶核或回声符石覆盖更多目标，同时承担派生伤害或逐跳伤害损失。

这些组合已具有范围、弹道追踪、目标选择与控制时长差异；本轮未进行长时间平衡试玩，当前数值属于原型参数。

## 卡池与界面

- 保留随机三选一、武器适用性检查和满级过滤。
- 稀有候选每轮有 25% 的放行机会，每组最多一张稀有道具 / 进化卡；不保证每次出现，也不保证目标配方。
- 保留至少一个适用于当前构筑的选择；只剩稀有选择时允许继续选，避免经验升级陷入空卡界面。
- 领取大量经验产生连续选择时，装备与路线变化立即影响后续候选；验证了卡池耗尽时能正常结束选择。
- 战斗状态条显示强化后的武器等级、道具数量与路线；详细效果放在现有暂停菜单，不新增战斗操作按钮。
- 卡牌明确显示正面效果和代价。暂停详情显示三槽武器等级、全部融合、道具及已选路线；小横屏可滚动查看。
- 使用既有字体、森林绿面板、浅黄文字及火水草色彩。继续采用 mattpocock `codebase-design`、项目内 `ui-ux-pro-max` 与 `frontend-design` 的模块设计和信息分层方法。
