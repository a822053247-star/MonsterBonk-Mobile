# Boss 环形弹幕

实现：`src/boss-barrage.ts`（固定步长发射与碰撞）、`src/boss-barrage-view.ts`（实例化弹体、轮廓、尾迹与预警）。由 `EnemyChallenge.movement` 启动，`advanceHazards` 推进；`EncounterView` 复用同一模拟渲染。

## 行为

保留荆冠兽王原有扇形技能：紫色扇形预警、普通7发/狂暴9发子弹、原蓄力和发射参数。新环形技能独立使用`barrage-windup` / `barrage`状态，交替选择缺口花环和旋转花瓣，预警1.35秒。新环形技能普通最多96发、狂暴最多144发，使用独立144槽弹池；原16槽普通远程/无尽变体弹池保持原规则。

- 攻击循环保留原“扇形 → 冲锋 → 召唤 → 冲锋”顺序，末尾追加环形技能；两个循环依次展示花环、花瓣。三种子弹技能均可在预览独立选择，扇形和环形的预警、发射、恢复互不覆盖。
- 缺口花环：普通3圈、狂暴4圈，粉色/紫色交替，保留0.72弧度的小缺口，逐圈偏转0.12弧度；各弹发射后保持直线路径，速度调制形成六瓣轮廓。
- 旋转花瓣：普通4臂、狂暴5臂，金色弹体连续向外展开，取消整段扇形缺口，从旋臂之间穿行。
- 青绿色扇区仅在花环、霜环蓄力时提示初始通道，其余技能不显示通道扇区；发射后没有安全区无敌效果。弹体使用现有地形遮挡和角色扫掠碰撞，命中伤害12。
- Boss在弹幕期间停驻，等弹体自然消散或被遮挡清除后才进入恢复与后续冲锋，避免冲撞与整段弹幕重叠。
- 暂停、捕捉小游戏期间随战斗一起冻结；死亡、重开与清场释放活跃状态。低画质减少尾迹，不改变危险弹数量；几何、材质及实例缓冲只分配一次，退出时释放。

## 无尽三位 Boss

`src/endless-boss.ts` 的普通和狂暴攻击序列均在原技能之后追加 `barrage-windup`，通过 `barragePatterns` 轮换专属弹幕。保留原攻击参数，共用上述弹池、伤害、预警、碰撞与暂停规则。

- 熔果暴君「熔火双旋」：两束各三发的橙红火流，逐批旋转发射；末批追加完整金橙色疏环（普通16发、狂暴18发）。普通13批、狂暴17批，狂暴发射间隔缩短、速度提高。原冲锋和扇形射击保留。
- 晶甲重炮王「交错晶阵」：蓝紫色细长晶体组成连续晶环，后一圈错开半个弹位，形成交错菱形空隙；取消统一扇形缺口，减少弹数并拉开圈间距，从错位弹体间穿行。普通4圈、每圈16发、间隔0.85秒；狂暴6圈、每圈18发、间隔0.8秒，并提高速度。原扇形重炮保留。
- 霜绒巨兽「霜雪涟漪」：冰白与浅蓝交替的慢速同心霜环，两条相对的0.64弧度通道按波次在正负0.14弧度之间交替偏移。普通3圈、狂暴4圈，狂暴每圈弹数和速度提高。原冲锋、地震保留，不附加冻结或减速状态。

三种弹幕均在发射时锁定直线路径，不追踪玩家；只有花环和霜环显示初始通道；火流、花瓣和晶阵保留圆形蓄力提示，不显示绿色扇区。Boss停驻至弹体散尽再恢复，后续冲锋和地震不会与当前环形弹幕重叠。

三位无尽Boss截图脚本：`artifacts/render-boss-variants.mjs`（直接浏览器渲染，不使用测试运行器）。截图为 `artifacts/boss-barrage-molten.png`、`artifacts/boss-barrage-crystal.png`、`artifacts/boss-barrage-frost.png`，更新后分别展示狂暴状态113、71、123发活跃弹体的画面。此次渲染未出现页面脚本错误；未运行测试或构建，未验证实战平衡。

## 无尽实战成长

正式接入路径为 `RunFlow.prepare` → `EnemyChallenge.spawnBoss`。无尽第6波使用荆冠兽王，第12/18/24波分别使用熔果暴君/晶甲重炮王/霜绒巨兽，之后三位变体轮换；普通/狂暴技能表均包含新环形弹幕，原扇形射击、冲锋和地震保留。加时仍只沿用原强制狂暴规则，不另叠时间倍率。

跨轮索引 `n=floor((累计波次-1)/6)`，Boss出生时锁定倍率，重开与换波重置：

- 扇形弹、环形弹与Boss地震使用现有接触伤害倍率 `min(1.40,1+0.05*n)`；基础伤害分别12/12/20，冲锋仍使用原24点接触伤害及其同一倍率。普通远程敌人和精英地震不套用Boss技能倍率。
- `src/balance.ts` 的 `cycleBossFrequency` 定义节奏倍率 `min(1.35,1+0.04*min(n,2)+0.10*ln(1+max(n-2,0)/2))`，与现有生命曲线相同采用前两轮小幅增长、后期对数缓升。
- 节奏倍率缩短环形弹幕批次间隔、弹体寿命、攻击后恢复和最迟接近等待；环形弹速同比提高，维持原最大传播距离。弹数、批次数、缺口大小和池容量不随深度增加。完整攻击循环包含固定预警，因此整体释放频率的提升小于节奏倍率。
- 保留环形1.35秒及原冲锋、扇形、地震预警；弹体散尽后再接后续攻击。整段环形蓄力与发射期间暂停新增危险护卫/普通怪冲锋或射击蓄力，既有动作正常结束。
- `EnemyChallenge.inspect().boss` 返回伤害/频率倍率，`barrage.inspect()` 返回当次锁定参数。预览页默认仍演示基础强度，不自动套用实战深度。

第12/18/24波环形弹伤害分别为12.6/13.2/13.8，节奏倍率约1.04/1.08/1.121；后期伤害最多16.8、节奏倍率最多1.35。该组参数按现有成长边界设计，尚未经实战平衡验证。本次按用户要求未运行测试或构建，仅检查源码接入与差异。

## 通道差异化修订

取消所有新技能共用的大扇形豁口。花环的小缺口逐圈移动，霜环用两侧交替偏移的窄通道；旋转花瓣、熔火双旋（包括收尾火环）、交错晶阵均不再剔除固定方向子弹。减少晶阵和收尾火环的弹数，同时放慢晶阵批次，保留可供穿行的弹间距。以角色碰撞半径0.62、弹半径0.22估算，18发均匀圆环在半径6处相邻弹心间距约2.08，大于合计碰撞直径1.68；这只是单圈几何估算，不能替代多层弹幕的实战验证。原扇形射击的紫色预警保持原样。

`BossBarrage.channelCount/channelWidth/gapAngle` 同时驱动发射剔除与初始通道显示，`dodgeHint` 提供按技能区分的战斗/预览提示。预警结束后标记消失，不跟随弹体显示安全路线，已发出的子弹仍保持锁定直线。无尽伤害与节奏成长继续生效。本次未运行测试或构建。

## 三位变体追加六种技能

每位变体的 `barragePatterns` 按固定顺序轮换三种弹幕，`barragePattern` 保留为预览默认选项。普通/狂暴技能表把三个弹幕段穿插在原冲锋、扇形或地震之间，按整局发射计数推进；半血切换与第30波起点偏移不重置弹幕轮换，重开/换波清零。预览可以独立选择每种弹幕，完整循环展示窗口延长到120秒。

| Boss | 新增技能 | 发射与躲避 |
|---|---|---|
| 熔果暴君 | 四向焰流 | 四束交叉火流按批次左右偏转；普通6批、每批12发，狂暴7批、每批16发；躲向交叉束间的斜侧 |
| 熔果暴君 | 熔核星爆 | 速度沿四瓣调制的完整疏环，普通4圈×12发、狂暴5圈×16发；各圈轻微转位，拉开距离穿过瓣间 |
| 晶甲重炮王 | 十字重炮 | 十字/斜十字交替，每束三发；普通6批、狂暴8批，每批12发；在炮阵之间换位 |
| 晶甲重炮王 | 棱镜聚焦 | 六个半径2.2的发射点向蓄力时锁定的角色位置齐射，每点三发；普通4批、狂暴6批，每批18发；紫色目标环显示锁定点，提前横移，后续不追踪 |
| 霜绒巨兽 | 六角飞雪 | 六条雪枝逐圈转位；普通4批×18发、狂暴5批×24发，从雪枝之间绕行 |
| 霜绒巨兽 | 错位雪幕 | 沿蓄力时锁定方向推进平行弹排，每排横向间距2.4、交替偏移正负0.6；普通4排×11发、狂暴5排×13发，冰蓝起始线标明出弹位置 |

新技能不使用统一扇形安全缺口，不附加燃烧、冻结或控制。全部复用固定弹池、12点基础伤害与无尽伤害/节奏倍率；普通最多96、狂暴最多144，池满跳过；目标、朝向与发射点在蓄力开始时锁定，弹体直线运动，地形阻挡与角色扫掠结算不变。发射后等弹体散尽才恢复，危险护卫/新蓄力错峰沿用原接入。额外目标环与雪幕线在视图构造时创建，暂停跟随模拟，清场隐藏，退出释放。
