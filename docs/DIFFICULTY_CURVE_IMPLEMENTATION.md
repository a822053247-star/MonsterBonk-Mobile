# 难度曲线实现与验收（1.9.1）

2026-10-21，在分支 `codex/local-work-20261021` 上基于 `6db569c3` 之后已有的外围出怪实现继续修改，与外围出怪代码一并提交。研究依据见 [DIFFICULTY_CURVE_RESEARCH.md](DIFFICULTY_CURVE_RESEARCH.md)。以下时间表属于本项目配置，不是对 Vampire Survivors 当前内部算法的复刻。

## 实现

- `wave-director.ts` 改成可变长度阶段表，独立控制背景速率、人口系数、护卫周期、两路入场组合及各类型配额。删除未生效的旧批次/护卫脉冲/特殊怪周期配置。
- `run-flow.ts` 背景只供给草团与晶屑虫，压力段独立调度快怪、岩甲、爆孢护卫；收割段提高背景供给且不新增导演护卫，已有危险怪继续存在。Boss自己的行动与召唤仍按原规则运行。
- 只在整局最初18秒提高人口预算，不再在换波后反复降低；人口系数为热身0.8、压力0.9、收割1。背景为当前护卫组和等待携宝兽预留槽位，事件可使用背景目标以上的硬上限空间。
- 近身拥挤仅把背景供给降至70%，不再取消压力事件。重大预警期间取消待入场护卫并延迟下一次事件2秒，结束后不追补积压。阶段切换也取消旧护卫余量。
- 护卫组合在同一主来向的±0.7弧度出生，两路各只间隔0.25秒；背景每四只变换来向。遇地图边缘/障碍仍由有限尝试选择合法外围点，因此并非保证固定方位。两者共用单次更新最多一只的调度门，不循环追补。
- 保留屏幕外出生、12–27出生距离、48次位置尝试、硬上限36/52/72/92/112/72、256敌人池及危险预警。未提高敌人基础HP/伤害、未削弱成熟连锁、大范围特效或单敌奖励，未按玩家实时输出缩放敌人。

## 六波时间表

时间均为本波战斗秒数；实际背景速率受拥挤、护卫优先、位置失败和人口上限约束。升级暂停与商店不消费战斗时间。

| 波 | 阶段（区间：阶段/背景只数每秒） |
|---|---|
| 1 | 0–20热身/1.5；20–45压力/1.8；45–65收割/2.8 |
| 2 | 0–12收割/3；12–42压力/2.6；42–60收割/4；60–70压力/3 |
| 3 | 0–28压力/3.4；28–48收割/5.5；48–62压力/3.8；62–75收割/6 |
| 4 | 0–10收割/5；10–40精英压力/4；40–60收割/7；60–75压力/4.5 |
| 5 | 0–25压力/5；25–55收割/8；55–70压力/5.5；70–80收割/8 |
| 6 | 0–10热身/2.5；10–25压力/3；25–35收割/5；35–50压力/3.5；50–62收割/5.5；62–78压力/4；78–84收割/6；84–90压力/4.5 |

压力组合从第一波每7秒两只快怪，逐步提高到第五波每3.5–4秒六只混合护卫。每阶段开始约2秒后才请求首组；未到引入时机或已达到类别配额时跳过该成员，不储存债务。收割段并不清除已存在威胁，因此阶段转换后的受伤和清场存在自然滞后。

## 连续局实测

运行 `npm run balance:campaign`，结果为 `artifacts/difficulty-campaign-results.json`。共45局：三角色×种子42/901/20261021×五种构筑/控制策略。使用真实 `Combat`/`RunFlow`、60Hz、真实受伤与经验拾取、仅获得的升级选择和可负担的最终商店商品，无预置技能、强制击杀、无敌或注入经验。

| 策略 | 观察局数 | 击败Boss | 存活战斗时间范围 |
|---|---:|---:|---:|
| 偏输出选卡、站桩 | 9 | 0 | 48.52–153.07秒 |
| 偏输出选卡、固定圆周移动 | 9 | 0 | 88.17–160.28秒 |
| 偏输出选卡、主动拾取/避让 | 9 | 6 | 357.07–429.88秒 |
| 优先联动选卡、主动拾取/避让 | 9 | 8 | 342.28–454.15秒 |
| 偏生存选卡、主动拾取/避让 | 9 | 0 | 235.15–455秒 |

这些是声明策略下的固定种子结果，不是真人胜率，不能据此证明平衡已经完成。偏生存脚本的失败包括Boss超时与受伤死亡；仍需真人验证其操作和输出取舍。偏输出脚本也可能在后续候选不足时选择联动卡，表格不是“绝不持有遗物”的隔离实验。

焰绒、种子42、优先联动示例：首次升级/融合27.55秒，成熟殉爆96.05秒；第二波压力受6伤、第三波首压力受18伤、精英压力受26伤。第五波首压力约25秒击杀91只，后续收割约30秒击杀217只，击杀速率由约3.6升至7.2只/秒；收割期间新增导演护卫为0。最终454.15秒击败Boss，27HP；真实连锁击杀413、最大3代/10节点，没有突破原3代/24节点预算。

优先联动的9局首次升级约27.45–37.27秒；火系三个种子的成熟殉爆约96.05–108.92秒。未通过强制掉落保证时点。部分经验在地面上积累，到第五波结算才回收，因此每段击杀经验不等于当段已收集经验；结果同时记录实际XP和选卡时间，不能只看击杀数推断等级。
