## 经济预算与长局边界

- 首商店前固定奖励225。首五波导演背景请求的时间积分约1121只，若全部入场并击杀且均为草团，约124金币；再计精英18、两次携宝共24及有限护卫收入，首商店约380–450金币作为初始预算带。请求积分不是实际入场/击杀保证，护卫占位、阻塞和走位都会降低收入。
- 后续两个商店之间包含上一段Boss60及五波225，共285固定金币；完整60秒Boss假设下六波背景请求积分约1570只，随背景速率系数1.03–1.24变化，相当于约180–216草团金币；精英、携宝与护卫另算。先以450–600金币作为正常长局预算带。Boss提前结束会减少背景请求，加时可能增加收入；晶屑每12杀1币，低于草团每9杀1币，不能把它套成同一收入。
- 首店425金币可购买130武器强化+105普通技能+150遗物，余40；或用普通商品/治疗与刷新换取更多选择。第71波商店基准190，550金币可购买230武器强化+190普通技能，余130；若刷新获得较便宜组合也可达到3件。2–4件是正常收入的目标带，不是强制购买上限；攒钱、额外奖励或长时间Boss加时可让单次购买更多。
- 生命与价格后段每步增量递减，不提高普通移动速度、缩短Boss预警或取消释放窗口。深至第600波，Boss生命约2.34万、普通技能约255，仍为有限数值；表中精确值为准。极深长局不承诺永远维持2–4件，收入效率低时可能只能购买1件稀有物。
- 当前60秒首五波比旧365秒更短，首Boss前真实等级是否达到原19–23级目标尚未验证；保留低级经验曲线和首通3–5件宝箱，避免在无实测时直接放大全部经验掉落。

后续实际长局应覆盖三起手、普通/控制/连锁构筑、至少30个固定种子与第6/12/18/24/36/48/72波。用RunFlow.inspect().economy读取最近12次商店的区间收入、进出金币、购买次数、商品与刷新花费，区分攒钱与当期收入；同时核对真实等级、可达经验和有效Boss耗时。成熟Boss中位数超过120秒先检查命中兑现率和生命曲线，不改预警。本文不宣称这些验证已经执行。
