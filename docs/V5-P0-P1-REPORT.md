# V5.0 P0 / P1 验收记录

日期：2026-10-19。范围来自根目录 `plan-v5.0.md`，仅工程安全迁移与焰绒技能融合最小原型。没有进入 P2。

## 交付行为

主菜单新增「单兽技能融合原型」：一只焰绒像素幻兽、一个摇杆、自动寻找并攻击敌人，无伙伴跟随、冲刺、跳跃或额外技能按钮。经验与三选一升级沿用现有系统，选择「命中分裂」后自动显示「爆裂火种 · 已融合」，正常恢复游戏。

融合链为 `spark + split-on-hit -> burst-seed`。分枝魔法增加同时发射的主弹；命中分裂增加命中后的两枚小火种，两者可共存。融合卡只加入新模式，兼容模式保持原八种卡牌。

主弹先对原目标造成一次直接伤害，再在命中点瞬时遍历一次附近其他敌人；原目标不重复吃本次范围伤害。派生最多两枚小火种，整个寿命内忽略原目标，不能爆炸或再次分裂。新生成的小火种从下一模拟 tick 开始更新，父弹槽位复用前已缓存所需数据。撞障碍不触发融合。
