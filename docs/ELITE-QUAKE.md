# 第四波岩甲精英地震

运行开发服务器后打开 `/elite-quake-preview.html`，默认进入可操作的「躲避演练」。点击开始后用 WASD / 方向键或左下摇杆移动；可选择每轮 2 / 3 / 4 / 6 处地震、半径 2.5～5.5（默认 4.6），连续释放或手动释放。第一处锁定角色位置，其余落点分散，每处有完整的 1.3 秒预警。落点与范围在预警出现后锁定，修改设置从下一轮生效；保留可在预警结束前到达的安全空间。命中通过正式 `Combat.hitPlayer` 扣血并共享受伤保护；死亡停止演练，重新开始恢复生命和清空危险区。暂停、失焦和后台清除输入并冻结模拟。

「特效查看」保留原来的单次攻击定格、循环播放、半速、拖动时间轴和完整/省电画质；玩家固定在危险区外。演练的可调多落点调度位于 `src/quake-drill.ts`，仅用于交互预览。正式第四波使用下面单独配置的可躲避地震。各模式共用 `EliteQuakeView`，预警和实际检测使用同一个半径。

## 正式闯关第四波（2026-10-23）

岩甲精英每轮最多释放 3 处固定落点地震：第一处锁定预警开始时的玩家位置，另外两处布置在保留的撤离方向后方。预警至少 2.2 秒，根据本局实际移速为步行撤离、0.8 秒反应和加速余量留出时间；预警开始后落点不再追随玩家。施放前检查一段约 4.92 单位的直线撤离路线，避开地形障碍和地图边界；找不到路线则延后施放，边界或障碍限制时减少辅助落点。该路线只预留地震和静态地形的撤离空间，不冻结其他敌人。

同轮落地最多扣 20 点生命；预警结束后才结算。落地后休息 3.6 秒再准备下一轮。暂停冻结，打断取消本轮预警，清波和重开清空落点与余波。未击杀精英进入第五波时沿用本机制；无尽模式及原单次特效查看沿用原时序。配置位于 `src/enemy-challenge.ts` 的 `CAMPAIGN_ELITE_QUAKE`。本次按用户要求未运行测试或构建。

显示表现：蓄力期间显示固定外边界、内收提示和边缘刻度；真实伤害帧生成定点地震事件，随后绘制双层地面震波、放射裂纹、抛起碎石与薄尘。余波持续 1.15 秒，只作反馈。每处预警边界对应玩家中心命中半径 `elitePulseRadius + 0.62`。

`src/enemy-challenge.ts` 持有固定的 3 个落点/冲击槽位与模拟时钟；暂停不推进，重开/清波清空。`src/elite-quake-view.ts` 使用共享几何、程序化地面着色器和固定实例批次；每处完整画质最多各 24 个碎石/尘团，省电各 10 个，保留完整预警和地面冲击。渲染不修改战斗状态，也不在每次施放时分配 GPU 资源。

验证入口：`tests/elite-quake.spec.ts` 检查伤害帧、脱离范围、打断、固定落点、时钟/重置和显示只读；`tests/elite-quake-ui.spec.ts` 检查实际渲染像素变化、时间轴、暂停、重播、画质和手机横屏。`tests/enemy-challenge.spec.ts` 保留现有精英/Boss 行为回归。

交互验证：`tests/quake-drill.spec.ts` 覆盖移动速度与边界、真实伤害、躲避、安全空间、配置锁定、固定池、死亡和重置；`tests/quake-drill-ui.spec.ts` 通过真实键盘与摇杆操作验证角色移动、多地震、暂停、范围设置及手机横屏。
