# 弹幕清晰度与受击朝向修复

日期：2026-10-19。接续阶段 D，集中解决子弹、特效堆叠以及敌人受击反向；未推进阶段 E。

## 发射节奏与显示

- 正式融合模式保留各武器独立冷却，增加轮流发射调度：同组主弹间隔至少 0.08 秒，武器组之间间隔 0.18 秒，每个模拟步最多发射一枚主弹。多重射击改为短连射。
- 三个武器显示各自冷却条和“待发 / 连射 / 剩余秒数”。暂停和升级选择期间冻结发射；换波和重开清空尚未发出的连射。
- 主弹大小 0.65，子弹大小 0.38，命中特效尺寸上限 1.55。爆炸实际范围以细环表示，减少实心遮挡。
- 同时显示最多 6 个主要命中特效，相距不足 1.1 单位时优先显示爆炸、水、草、普通命中。此筛选只影响画面，不删除伤害、减速或融合触发。
- 缩减尾迹，关闭特效深度写入，降低正式模式受击白闪强度，保留敌人轮廓。

数值集中在 `src/combat-clarity.ts`。这是本项目的初始调校值：错峰调度会限制极限攻速构筑的持续射速，没有额外补偿单发伤害。弹道交叉、敌人聚集时仍可能局部重叠，未加入弹珠间物理互斥。

参考：[BALL x PIT 开发者官方更新说明](https://blog.playstation.com/2026/01/26/ball-x-pit-the-regal-update-launches-today/)。采用其连续发射与技能组合的参考方向；没有将本项目参数宣称为原作数值，也未证实原作所有球都有统一 CD 或绝不重叠。

## 敌人受击强制转向

最小浏览器复现：单个敌人向左追击，沿反方向受到伤害后，下一帧精灵从 left 变为 right。执行 `npx playwright test tests/enemy-hit-facing.spec.ts --config playwright.chrome.config.ts --reporter=line` 时，修复前稳定报 `Expected: left / Received: right`。

已排除伤害处理直接改朝向、白闪改变方向贴图两项原因。根因是显示层用包含击退的总位移选取方向贴图。

修复将主动移动和外部击退分别进行障碍碰撞处理，记录主动移动的实际位移（包括绕障滑动），供朝向和行走动画使用。击退仍改变敌人位置并衰减；死亡动画沿用主动移动方向，敌人池重新使用时重置移动记录。三类基础敌人均使用同一逻辑。
