# 《幻兽幸存者》V5.0 正式设计规则

2026-10-19，依据根目录 `plan-v5.0.md`。本文件为当前规则；已追加水草四融合开发验证阶段，P1 条目保留为既有实现说明。原文件完整存为 [GDD-V4.0.md](GDD-V4.0.md)。

## 核心方向

原创像素风 2.5D 幻兽进化肉鸽手游，目标 Android / iPhone，正式单局目标 8–12 分钟。核心循环为「一只幻兽上场 → 自动攻击 → 获得经验 → 暂停选强化 → 技能融合 → 特殊进化」。当前 P1 没有正式胜利条件，不代表完整单局。

1. 每局只有一只幻兽在场，玩家直接控制它，一个虚拟摇杆控制移动。
2. 自动索敌、攻击和释放技能，不增加主动攻击、冲刺、跳跃或技能按钮。
3. 敌人死亡掉落经验，接近自动吸收；升级暂停，从随机卡牌中选择强化，选择后恢复。
4. 种族基础攻击、通用强化、特殊融合是三层能力，满足配方后自动融合，无额外合成操作。
5. 地图物品未来通过接触自动交互；不探索也必须有机会通关，保持高密度割草体验。
6. 六波、商店、Boss、随机区域和可选探索保留为未来目标，不属于本轮交付。

禁止添加塔防、弹珠捕获、弹珠机、家园、背包、复杂装备管理、离线挂机、行动时间轴、弹药或额外战斗操作按钮。

三兽编队、伙伴跟随、属性羁绊和招募队友不再属于正式核心；保留源码、测试、素材与独立兼容入口。旧自由器官进化不恢复为主要玩法。

## 物种与三层技能

|物种|属性|基础攻击|方向|
|---|---|---|---|
|焰绒|火|火花弹 spark|爆炸、分裂、范围输出；P1 已实现爆裂火种|
|泡泡螈|水|水泡弹 bubble|减速、控制、扩散；本轮提供单兽开发验证入口|
|芽刺兽|草|叶刃 leaf|穿透、连锁、多段；本轮提供单兽开发验证入口|

通用技能方向包括伤害、攻速、多重发射、命中分裂、穿透、连锁弹射、范围扩大和生命强化。P1 复用现有卡牌并新增「命中分裂」；本轮仅在水草开发入口增加「范围扩大」「连锁弹射」配方卡。

「分枝魔法」增加同时发射的主弹数量；「命中分裂」在主弹命中后派生子弹，两者可共存。灼热贯穿弹不在开发范围。本轮只新增深海泡影、连环水爆、荆棘散射、跳跃荆棘，既有爆裂火种保留。

## P1：爆裂火种

配方：`spark + split-on-hit -> burst-seed`。升级卡「命中分裂」上限 1 级，只出现在单兽技能融合原型的随机卡池；历史模式保持原八种卡牌。

主弹命中敌人，主要目标先承受直接伤害；命中点发生一次范围爆炸，对附近其他敌人结算一次范围伤害，再沿主弹方向两侧派生最多两枚小火种。小火种可击中其他敌人，整个寿命内忽略原目标，不能再次分裂或爆炸。撞上障碍不触发融合。

|P1 调试参数|值|
|---|---|
|主弹|沿用焰绒 18 基础伤害、0.44 秒间隔、10.5 射程与既有强化|
|爆炸半径|1.35 世界单位，圆形敌人半径参与相交判定|
|爆炸伤害|该主弹伤害的 30%，排除原目标|
|小火种|最多 2 枚，各为该主弹伤害的 35%|
|分裂角度 / 寿命|相对主弹 ±60° / 0.45 秒|
|最大代数|1，新火种下一模拟 tick 才移动及碰撞|
|爆炸动画|0.4 秒，视觉不再结算伤害|

参数集中在 `src/fusion.ts`，属于原型调试数值。所有伤害沿用统一结算、击杀与经验入口。获得卡牌之前发出的普通弹维持原行为。未来可扩展配方表，不新增通用脚本语言或编辑器。

## 工程、素材与生命周期约束

- 复用 Game / Combat / Progression / PartySystem / CombatView，单成员编队提供当前单兽攻击来源，不复制引擎。
- 保持投射物 24、敌人 48、效果 48 个槽。池满时少派生或不派生，主弹与爆炸伤害保留。不提高敌人上限。
- 动画使用模拟子弹年龄和效果剩余时间；暂停、选卡、后台、死亡停止推进；重开清空技能、弹体与效果。
- 使用现有焰绒 PNG。技能原图保留，规范化副本采用最近邻、透明裁剪、128×128 单帧；素材 A 为 4×4 战斗动画，B 为 3×1 卡牌和融合图标。
- 贴图失败保留程序化子弹、拖尾、火环和粒子；图标失败显示原 SVG 和技能文字。
- 保留已有随机草场及种子复现，不在本轮开发新区域或探索事件。

## 菜单与兼容

「单兽技能融合原型」为 V5 P1 入口。「随机草场冒险」保留此前单兽地图验收。「三兽编队原型」保留三物种跟随和独立自动攻击。底部「单兽回归」「犄角试炼」「三波闯关」保留旧操作与规则。正式融合模式不调用伙伴跟随，不开放冲刺或跳跃。

## 本轮边界：水草四融合开发验证

P1、P1.5 与四种水草融合已存在。按后续授权，主菜单现已增加幻兽选择：焰绒、泡泡螈、芽刺兽任选其一，每局只上场一只。仍不增加商店、金币、六波正式挑战、Boss、新区域、蛋、祭坛、进化或其他融合。旧三兽模式保持历史基础攻击和八种卡牌。

主菜单点击「选择幻兽」，选择角色后点击「开始挑战」；也可关闭选择面板再从主菜单开始。默认焰绒，重开保留本次所选幻兽，返回菜单可以换兽。三只角色复用已有八方向动画及对应基础攻击、升级卡池与融合。`fusionDev=paopaoyuan/yacishou` 仅保留为兼容预选参数，玩家在菜单手动选择后以新选择为准；三兽兼容和旧玩法不受选兽影响。

| 新配方 | 触发与当前调试效果 |
| --- | --- |
| 水泡弹＋范围扩大＝深海泡影 | 命中扩散，半径 2.2，附近其他敌人承受当前弹伤害的 40% 并减速 |
| 水泡弹＋连锁弹射＝连环水爆 | 每次命中半径 1.1 水爆，附近其他敌人承受 25% 伤害；最多跳向两个新目标 |
| 叶刃＋命中分裂＝荆棘散射 | 主叶刃首次命中派生最多三枚荆棘，各为当前弹伤害的 40%，不再分裂或连锁 |
| 叶刃＋连锁弹射＝跳跃荆棘 | 主叶刃命中后最多跳向两个新目标，不重复直接命中已记录的目标 |

单兽融合模式基础攻击：水泡直接命中减速 1.5 秒、移动速度乘 0.55，刷新持续时间而不叠乘；叶刃可额外穿过一个敌人。以上仅在单兽融合模式启用，历史三兽基础行为保留。

连锁最远 5 单位，跳转后伤害乘 0.8；不会透过障碍锁定目标。跳转采用真实飞行投射物。叶刃跳转成功后不再额外穿透，最多直接命中三只。散射角度为 -45° / 0° / +45°，寿命 0.4 秒，下一模拟 tick 起运动，整个寿命忽略原始目标。

同物种两条配方可以同时生效。深海泡影与连环水爆共用同次命中的范围结算，采用深海泡影的半径与倍率，保留连锁；不重复叠加两个水爆。连续不同命中产生的范围伤害可波及同一敌人，连锁直接命中的历史仍独立去重。荆棘散射仅在主弹第一次命中触发，子荆棘没有配方，不形成递归。

投射物发射时保存融合状态，之后获得的新强化不追溯更改飞行中弹体。所有伤害、击杀和经验仍通过 Combat 统一入口；池满时减少派生，直接伤害和范围伤害保留。水草复用现有实例化环、弹体和粒子显示，使用水蓝与草绿区分，不借用焰绒火焰图集。数值为原型调试配置，尚无手机性能或平衡结论。
