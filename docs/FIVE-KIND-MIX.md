# 五类怪潮 / 赤团与晶屑虫分工 / 爆孢护甲

## 游戏内设计（正式六波）

1. **五类普通来敌使用同一生成池与候选权重**，不再是普通批次之外再按第二只钟表塞满晶屑虫、爆孢怪。每12个候选生成位置：**赤团5、疾芽2、岩甲2、晶屑虫2、爆孢怪1**。循环使用实际生成成功的ID确保固定随机种子重放稳定。因为阶段解锁、同屏配额和安全出生，**实际生存比例不保证严格等于权重**。携宝兽与第4波精英/第6波Boss仍是独立、稀有的事件，不挤入普通权重。
2. **赤团：原地拍地**。正式六波里靠近玩家1.65世界单位后停止移动，脚下显示半径1.35的圆形危险区 **0.7秒**，随后原地发动0.2秒近身重击，不会冲刺，结束后有1.1秒明显恢复期。周围2.7单位内同时蓄力的赤团最多2只，避免怪潮里预警叠成一片。玩家离开圆形区域就能躲开，经典模式依旧沿用原AI；不改变已有接触伤害和动画素材。**疾芽才是带方向预警的远距离扑击者**，侧向闪避应对它。
3. **晶屑虫：穿插游走**。它比赤团更轻，更快，以ID分相位的正弦横摆接近玩家；仍遵守障碍/敌人分离与原有近距攻击，不与赤团共享“蓄力肩撞”动作。原本独立的 `Combat.spawnCrystalSwarm` 接口保留给旧测试和外部玩法调用；六波导演改为统一权重生成零散的晶屑虫。
4. **岩甲：重步推进者**。正式六波维持125基础生命（旧模式仍100）。不再借用赤团的停步/蓄力/拍击状态机；始终以较慢速度持续压近玩家，转向响应从普通14调低到3.2，表现出重甲的方向惯性。降低步伐摇晃和行走节奏，贴身时才触发原有16点接触伤害，碰撞距离为本体半径+0.17。没有赤团的圆环预警，也没有疾芽的直线突进。玩家用走位绕过缓慢推进的岩甲，不能被近身包围；第四波精英与第六波Boss继续使用各自独立技能，不继承普通岩甲推进逻辑。
5. **爆孢怪**：在正式波次基础血量从28**提高至140**，再按波次血量倍数放大，例如第五波308血。玩家需要专门投入伤害或抓住它爆炸连锁的时机。普通孢子爆炸对玩家仍为12点、对其他敌人45点；对其他爆孢怪产生**7倍特殊连锁克制**，让清怪连锁仍可行，而不是因其更肉导致前一阶段的爆孢玩法失效。经典/旧模式爆孢的基础28 HP不变。
6. **公平预警和配额**：晶屑虫最早第1波8秒参与；爆孢仅第2–6波对应的14/18/25/16/28秒后参与；处于精英/Boss蓄力或已有未爆孢子预警时跳过新增爆孢怪，后续候选替换赤团。同屏孢子按导演规则最多2只，且受16个爆炸事件容量限制。普通敌人总上限仍是60/90/120/160/200/120。

## 与已有状态机兼容

- 前四波没有商店，均为3.5秒战场休整后自动继续；第五波结束休整后唯一商店。
- 携宝兽仍按独立事件出场，可获得先前定义的成长与免费商店刷新权益。
- 不更改经验/金币结算、Boss与精英HP、进化规则、角色攻击成长和素材。
- `scripts/wave-balance.ts` 原始种子可复现新的五类来敌覆盖情况。
