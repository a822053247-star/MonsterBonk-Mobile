## 实际改动

| 模块 | 结果 |
| --- | --- |
| `src/camera-25d.ts`、`src/game.ts` | OrthographicCamera、固定 45°、同一锚点平滑位置与注视点；镜头不旋转、不随树木收近；横屏至少 28 世界单位宽、17 单位投影高度 |
| 输入映射 | 屏幕右为 +X，下为 +Z；逆向补偿俯视投影压缩，使斜向摇杆对应屏幕斜向，同时保留模拟量强度及世界移动速度 |
| `src/monster.ts` | 几何体四足焰绒；按材质及动画组合并网格；呼吸、四肢摆动、冲刺倾身、受击闪色、眨眼及摆尾 |
| `src/creature-data.ts`、`src/organ-view.ts` | 六种器官 ID 与槽位元数据，头/背/尾独立 Group，位置与缩放配置；仅制作犄角和甲壳两个缓存占位对象 |
| 器官接口 | `equipOrgan(id)`、`unequipOrgan(slot)`、`configureSockets(layout)`；同槽至多一个器官，未制作的器官返回 false，更新插槽配置保留已装备对象。显示与战斗数值完全分离；未添加装备 UI 或真正进化流程 |
| `src/world.ts` | 原平地与实例化场景复用，中央草场、风语林地、岩晶遗迹三种地面颜色；缩小并半透明化树冠、压低岩石，草丛采样由 1400 减为 320，移除天空球、云和远山生成 |
| `src/ui.ts`、`index.html` | 焰绒命名、简易 SVG 头像，手机仅保留摇杆与冲刺；原安全区域、Pointer Events、升级和暂停布局继续使用 |

`src/combat.ts`、`src/combat-view.ts`、`src/progression.ts`、`src/input.ts`、`src/quality.ts`、`src/audio.ts`、依赖及 Vite 配置与基线一致。地图半径、136 个碰撞体、敌人/弹体/经验池上限、伤害、速度、升级曲线、技能配置及游戏计时规则未变。原有键盘 J 的纯表现跳跃保留，移动端无跳跃按钮，跳跃不改变地面战斗或碰撞。

镜头避障模块 `src/camera-collision.ts` 保留供历史回退，但当前 Game 不再导入或执行。没有新增依赖、物理引擎、实时阴影、纹理下载、后处理或骨骼系统。Capacitor 兼容的相对资源路径、静态 dist 和 Safari 15 构建目标保留；尚未接入原生安装包。

## 实际测试及结果

1. 改造前及改造后 `npm run build` 均成功。最后构建在插槽位置微调后再次成功。Three.js 分包仍有约 544 kB 的体积提示，此提示不影响构建，未为消除提示引入依赖或更改架构。
2. 执行 Chromium 全套回归；首次 46 项全部通过。增加两个新场景后执行 `npm test`：96 个用例中 91 通过、4 个 WebKit/CDP 用例按条件跳过、1 个新增测试夹具失败。失败原因是随机敌人在读取网格前已死亡；已用固定的三类测试敌人修正夹具。
3. 修正后执行 `npx playwright test tests/25d-model.spec.ts tests/25d.spec.ts --reporter=list`：9 通过、1 个 WebKit/CDP 用例跳过。结合未受夹具修改影响的全套回归，92 个不同用例均已有通过结果；不是单次全套 92 通过的声称。过程中另修复新增夹具的 UTF-8 声明，及两个测试进程共享报告目录造成的测试输出冲突，最终验证串行执行。
4. 覆盖：实际浏览器摇杆、Chromium CDP 多点触控与四个方向/斜向移动、松手与冲刺独立、固定镜头四元数、画面宽高比、玩家地面 Y=0、敌人网格脚底在地面轻微起伏、三类敌人、自动射击命中、经验拾取、升级三选一及溢出、升级/暂停冻结、重开清理、安全区域、旋转提示和模拟后台事件。
5. 器官验证：同槽重复装备不叠加，独立头背插槽可同时挂载，更新形态插槽配置保留器官，缓存对象重复使用，卸下的缓存资源在退出时释放；未制作的器官不会清空当前装备。
6. `node artifacts/25d-production-smoke.cjs` 在 Chromium 和 WebKit 的生产 dist 上通过：自然击杀、移动冲刺、设置、暂停计时、重开初始值、无错误界面、无 pageerror，生产页面不暴露开发诊断。
7. `node artifacts/25d-world-check.mjs` 对比 Git 基线与当前场景生成结果，136 个碰撞体的顺序、坐标和半径哈希完全一致。结果见 `25d-world-check.json`。此脚本的 Canvas stub 仅用于构造数据，不用于声称渲染通过。
8. `git diff --check` 通过，核心玩法/依赖文件差异检查通过。

测试环境是 Windows 桌面 Playwright Chromium/WebKit。已覆盖 568×320、844×390、932×430 等手机横屏视口、触控模拟及安全区域变量模拟。截图已实际打开检查。桌面 WebKit 不能代替 iPhone Safari 真机，后台模拟不能代替真实 App 切换；**未进行 Android/iPhone 真机测试，未声称达到 30/60 FPS**。
