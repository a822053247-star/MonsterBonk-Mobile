## 时间与触发条件

固定种子 20261021，正式 Game.step 以 1/120 秒推进。夹具关闭自动刷怪并控制单次施法，不修改战斗伤害、碰撞、范围或攻击间隔。
每个场景内部不重开或切换敌人；事件生命周期由真实 CombatEffect.time/duration 驱动。HUD 只显示整秒，报告显示 combatTime 四位小数及 effect age。

蒸汽序列先捕捉实际水命中与 wetTime > 0、steamBursts = 0、装备沸腾核心，再发射火花弹。真实碰撞后 steamBursts = 1，半径仍为 2.5，持续时间仍为 0.55 秒。
采样包含刚触发、0.025、0.12、0.28、0.46、0.535 和 0.57 秒；最后一帧事件已到期且雾团/轮廓消失。
负对照分别缺少核心、缺少水命中，均为 0 次蒸汽。爆炸序列使用现有爆裂分裂升级，未新增爆炸伤害逻辑或调整该升级数值。

## 视觉改动和预警测量

当前蒸汽正常显示时仅保留蓝色雾团，已取消地面轮廓圈；只有贴图加载失败或配置关闭低画质雾团时使用轮廓回退。移除默认圈后的生命周期、预警与故障验证 8/8 通过，见 `../vfx-steam-no-ring-tests.txt`。

仅调整预设/渲染参数：火/水弹体显示比例 1.3/1.1，命中闪光高度，复用已有水系图集帧，蒸汽高度/亮度/轮廓。
手机短屏的固定 HUD 会遮住角色附近的部分像素，因此使用固定的左下方攻击方向展示飞行路径；没有修改 HUD，也没有移动或拼接截图中的元素。

预警测试将现有真实预警状态锁定在待比较姿态，不把它当作敌人 AI 时序测试。每个状态做同一帧四次 GPU 渲染：VFX+预警、VFX、预警、都关闭。
只在预警原本可见的像素上比较其贡献是否仍超过 RGB 差阈值 12，计算 retained/baseline。它证明这些实际重叠场景下的可辨认性，不声称所有敌人密度/所有实机设备下绝不遮挡。
统计和完整原始状态见 `summary.json`、`*-warnings.json`。原始图未加特效、未合成、未插值；HTML 仅按时间切换图像。

本轮没有重跑之前 1030 项全量套件；此前既有失败的原源码对照见 `../vfx-validation.md`。本轮相关 68 项包含旧粒子/清晰度/触发遗物/精英Boss预警回归测试，没有删除或跳过原断言。
