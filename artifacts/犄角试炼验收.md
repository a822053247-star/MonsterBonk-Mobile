# 犄角试炼：第一轮玩法实验

入口：启动游戏后点击主菜单右下角「犄角试炼」。左下摇杆移动、右下冲刺；电脑 WASD / 方向键、空格 / Shift。原「开始冒险」继续使用旧模式。

## 本轮玩法

- 开局确定获得冲锋犄角，立即体验器官能力，不依赖随机升级抽取。当前只建立这一个试炼，没有扩展完整器官掉落、交换或进化树。
- 冲刺前方扫掠命中：32 伤害、击退、0.42 秒硬直，同一敌人每次冲刺至多命中一次。穿过目标也能命中；背后目标、出生预警中的敌人和被障碍隔开的目标不受击。沿用已有击杀、经验掉落、拾取和音效。
- 快速怪在 7.5 距离内锁定方向，蓄力 0.7 秒，沿黄线扑击 0.34 秒，然后休息 1 秒。蓄力和休息时无接触伤害；冲刺犄角可以打断蓄力和扑击。青环提示硬直或休息。
- 小目标：累计冲锋命中 6 次。达成后继续练习，不增加结算、奖励或 Boss。

这轮主要验证「观察敌人意图 → 侧移躲避或主动冲刺打断 → 趁停顿反击」，让移动和冲刺有主动决策。开局确定装备也减少等随机卡牌才体验到核心玩法的问题。是否更好玩仍需实际试玩反馈。

## 保留与边界

- 地图、固定正交镜头、输入、移动速度、冲刺速度/距离/冷却、原武器数值、8 项升级技能、经验曲线和池上限均保留，没有新依赖。
- 仅试炼快速怪生命从旧模式 18 改为 54，避免在展示扑击前被自动攻击一发击杀；其接触伤害仍为 6，掉落仍为 2。原模式三类敌人的数据完全不变。
- 规则参数放在 `src/trial.ts`；战斗逻辑不依赖角色模型。精灵模式用 HUD、金色冲刺轨迹和命中反馈表达能力，没有把 3D 犄角强贴到 PNG 上。`?character=3d` 的旧程序化模型会显示已有占位犄角。等待用户生成的 Tripo 模型，不在本轮制作素材。
- 预警、箭头和停顿圆环使用固定容量实例化批次，共享几何体和材质。无实时阴影、新物理引擎或后处理。小横屏调整入口和提示卡，避开摇杆及模拟安全区域。
- 开工时工作区干净；建立检查点分支 `checkpoint/before-horn-gameplay-20261018`（`49c17db`），在 `feat/horn-gameplay-trial` 开发。

## 验证

- `npm run build`：通过 TypeScript 检查和 Vite 生产构建。保留已有 Three.js 分块超过 500 kB 的体积提示。
- 新增逻辑测试：扫掠命中、单次命中限制、遮挡、经验路径、打断、扑击跨帧碰撞、状态冻结与复用、30/60/120 Hz 渲染调度下相同固定步长结果。
- 新增浏览器测试：真实 Game 对象下触控冲刺命中和打断、暂停/重开、返回旧模式、三选一卡牌冻结与恢复、预警实例、844×390 和 568×320 横屏，以及模拟左右 44 px / 底部 21 px 安全区域。
- 旧模式基线对比：与 Git `49c17db` 的原 `Combat` 在相同随机种子、地图障碍、移动轨迹下逐步比较 21,600 次状态，包含 37 次升级选择，全部一致。见 `horn-classic-parity.json` 和可重跑脚本 `horn-classic-parity.mjs`。
- 完整 Chromium / WebKit 回归：120 通过、4 跳过、0 失败（4.1 分钟）。4 项跳过均为 WebKit 不支持的 Chromium CDP 注入测试，相应 Chromium 测试通过。日志：`horn-test-output.txt`。生产构建在两种浏览器中启动、自动击杀、暂停计时冻结、重开和返回旧模式均通过，页面错误为 0；见 `horn-production-smoke.json`。

测试环境是 Windows 桌面浏览器模拟手机视口，不是真实 Android 或 iPhone；不据此承诺真机帧率。WebKit 自动化也不等于 iPhone Safari 真机验证。
