# MonsterBonk Mobile 第三阶段：经验升级与技能强化

日期：2026-10-17（北京时间）。版本 0.3.0，在原项目内修改，没有新增运行依赖。

## 交付范围

- 经验从 8 点起步，每级需求增加 4 点；保留溢出经验和多级升级队列。
- 升级暂停整个游戏循环和战斗模型，中央三选一，触屏或键盘选择后继续。
- 八种技能：魔法弹伤害 +20%、攻击频率 +15%、投射物 +1、生命上限 +20、移动速度 +10%、锁敌范围 +15%、环绕球、范围冲击波。
- 统一数据配置、同类基础值累加、不同技能同时生效、逐项等级上限、卡牌不重复、满级退出卡池。
- 全技能总计 34 次强化、最高 35 级。最后仅剩一两种可强化技能时只显示有效选项，全满后不再弹出空界面。
- 伤害和射程影响真实魔法弹，射程同时延长弹体寿命，多重弹始终保留一发中心弹。
- 环绕球最多 3 颗，共享每敌人 0.55 秒命中间隔；冲击波按扩散半径结算，每波每敌人只命中一次。
- HUD 显示等级、本级进度、累计经验以及动态生命上限。
- 升级打开时清空并释放旧摇杆/键盘/冲刺输入，HUD inert；仅新按下并在当前卡牌松开的手势可以选卡。新卡有 180ms 防连点保护，旧卡延迟点击无效。
- 重开与返回菜单清理本局等级、经验、强化、未选奖励、环绕角度、波纹与所有旧战斗对象。
- 原地图、角色、摄像机和多指摇杆保留。

## 代码位置

- `src/progression.ts`：经验曲线、八种技能配置、等级上限、计算、有效卡池与升级队列。
- `src/combat.ts`：应用强化到实际攻击、两个新技能的命中与冷却、升级时模型冻结。
- `src/combat-view.ts`：环绕球、轨道和扩散冲击波的实例化显示。
- `src/game.ts`：升级状态、指针隔离、防误选、恢复、移动加成、HUD 与重开。
- `src/ui.ts` / `src/style.css`：卡牌、等级进度、横屏和安全区域。

## 验证结果

1. **`npm run build` 成功**，严格 TypeScript 检查与 Vite 生产打包通过。
2. **完整 `npm test`：62 项成功、2 项跳过**。两个跳过项都是 Windows WebKit 无法使用的 Chromium CDP 多指注入；对应 Chromium 测试成功。WebKit 普通触屏选卡和页面流程测试成功。
3. 新增 9 项升级/技能单元测试（在两个项目配置下执行）：精确阈值、溢出和多级队列、非法输入、唯一有效卡池、全部满级、数据叠加、真实弹体、攻速/生命、环绕球、冲击波单波命中/周期/冻结、重置。
4. 新增 6 项真实 Game/UI 浏览器集成测试：暂停与触屏选择、连续奖励/旧点击、568×320 安全区域、旋转与后台、技能共存与重开、最后一张有效卡，以及旧摇杆手指释放不选卡。
5. **正常游戏流程实测成功**：在主页面仅通过鼠标操作虚拟摇杆、读取诊断状态，没有注入经验或敌人；实际击败 4 只敌人并吸收 8 点经验后达到 2 级，出现卡牌，冻结检查成功，选择环绕球后恢复游戏。记录为 `natural-level-up.json` 与 `natural-level-up.png`。
6. **生产包 smoke 检查成功**：通过 `vite preview` 打开，菜单、移动、暂停与重开正常；重开恢复 `Lv. 01`、经验 `0 / 8`、生命 `100 / 100`，升级面板隐藏，没有页面异常，也没有暴露开发诊断对象。记录为 `progression-production-smoke.json`。

浏览器场景通过独立测试页面安排边界条件，使用真实 Game/UI 模块；测试专用控制不进入生产页面。后台测试通过可控 visibility 输入检查暂停逻辑。Windows WebKit 抓取 WebGL 截图可能不稳定，不代表 iPhone 真机结果。

## 性能与设备边界

保留原 48 敌人 / 24 魔法弹 / 96 经验球 / 48 组特效的固定池；新增最多 3 颗环绕球和 2 组冲击波，采用共享几何体与实例化批次。没有新增实时阴影、后处理、网络请求、多人联机或账号系统。

Three.js 独立 JS 超过 Vite 默认 500KB 提醒阈值，仍为体积提醒，构建成功。没有实际 Android/iPhone 真机连接，尚不能确认实机 FPS、发热或系统触控差异。建议重点验证升级时保持双指、老手指滑到卡牌后松开不选卡、新点击选卡、恢复后摇杆复位、连续升级和升级中切后台/旋转。
