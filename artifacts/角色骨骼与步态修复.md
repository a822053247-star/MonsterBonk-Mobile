# 焰绒 GLB 骨骼与步态修复

## 复现与诊断

输入：`public/assets/characters/fire+fox+3d+model_Clone1.glb`，Tripo 导出，8,158,820 字节，12,311 个顶点、9,948 个三角面、28 根骨骼，包含一个约 2.54 秒的 `preset:quadruped:walk` 动画。

实际加载并采样了原动画。它会令腿部缩拢、脚掌折叠，整体呈蹲跳姿态。原后腿链不对称：`tripo::0_Right_Limb_0…3` 四节，而 Left 为 `0…2` 三节；一侧末端关节位于模型离地约 0.136 的高度，另一侧约 0.049。名称经 GLTFLoader 清理后会去掉冒号。完整骨骼位置、权重分布见 `fox-rig-analysis.json`，原 GLB 元数据见 `fox-source-inspection.json`。

模型的静态外观与面数可用，因此这次修复骨架、权重与动画，不要求重新生成模型。

## 修复内容

- 单独生成 `public/assets/characters/yanrong-repaired.glb`，不覆盖输入。原文件已在 Git `8e77ccc` 保存，检查点分支为 `checkpoint/before-fox-animation-repair-20261018`；修改在 `feat/fox-animation-repair`。
- 14 根简化骨骼：身体、尾巴及四条三节腿。根据原蒙皮的腿部分区重新分配权重，低位脚掌/脚趾以刚性脚掌权重为主，避免脚趾折叠；各顶点权重重新归一化。
- 用双节腿 IK 烘焙 0.72 秒循环，对角两腿交替迈步，脚掌维持地面方向；身体只轻微起伏，尾巴轻摆。固定膝关节弯曲方向，并为膝关节留出弯曲余量，避免过伸时的瞬时翻转；最终相邻烘焙帧的最大关节转角约 5.02°。动画没有水平根位移。
- **原顶点位置、UV 和三角索引逐值保持一致**；保留三张材质贴图，导出时限制最长边 1024。修复版 3,219,284 字节，约 3.2 MB。SHA256 及原文件与 Git 的一致性检查见 `fox-asset-audit.json`。
- 游戏默认加载修复版。`MonsterModel` 仅管理显示、动作混合和资源：移动渐入行走、停步渐回静态姿态，冲刺加快步态并略微伸展/前倾，受击闪光，重开复位。脚底锚定，模型尺寸按横屏视口调整。
- 使用几何的资产本地绑定姿态边界归一化尺寸，避免异步加载时蒙皮世界矩阵尚未更新而得到错误大小。接入保留独立器官显示插槽和旧占位器官。
- GLB 加载失败回退精灵，再失败回退程序化角色。`?character=sprite` / `?character=3d` 可明确选择旧显示方案。

本轮没有改动 `combat.ts`、`combat-view.ts`、`progression.ts`、`input.ts`、`world.ts` 或 `camera-25d.ts`。不改玩家世界坐标、移动/冲刺速度、碰撞、数值或升级配置。模型自身的静态非对称造型保留；这是低成本简化步态，不包含完整跑步、攻击、表情或专业手工蒙皮。

## 实际检查

- `npm run build`：TypeScript 与生产构建通过；Three.js 分块仍有体积提示，GLTFLoader 使用已有 Three.js，无新增依赖。
- 两浏览器的资产采样：全部四只脚的有效脚掌顶点均有前后位移 >0.07、抬脚 >0.02（模型原始单位）；权重总和误差 <0.000001，循环首尾吻合。所有顶点高度处于 -0.003 至 0.9 的范围内，运行时另有 0.008 的地面余量及等比缩放。
- Game 实测：行走渐入/停步渐出、暂停冻结动画、连续重开 GPU 资源数不增长、GLB/程序化显示下玩法结果一致、GLB 缺失回退精灵。
- 横屏模拟：844×390、568×320；旧摇杆、多指冲刺、三选一、升级暂停、后台暂停、犄角试炼等完整回归见 `fox-test-output.txt`。
- 完整回归 126 通过、4 跳过、0 失败（4.7 分钟）；跳过项为 WebKit 无法使用的 Chromium CDP 注入测试。随后对膝关节曲线做最终平滑，最终 GLB 的模型专项测试在两浏览器中重新执行，6 项通过，见 `fox-final-model-tests.txt`；同步重跑了资产审计及下述生产检查。
- 生产构建 Chromium / WebKit：模型请求 200、实际显示截图已检查，自动攻击击杀、暂停、重开均通过，页面错误为 0；开发诊断未出现在生产页面。见 `fox-production-smoke.json`。

测试环境为 Windows 桌面浏览器模拟手机视口，不是 Android/iPhone 真机帧率测试。
